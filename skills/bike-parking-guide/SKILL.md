# 校园自行车停放指南

回答校园自行车停放、拖车、领车、车牌类问题时使用本指南。内容以事实为准，不要编造额外楼栋或位置。

## 第一步：快速判定

先分车型，再看楼栋，最后检查是否违规。

### 按车型

| 车型 | 停放位置 |
| --- | --- |
| 共享单车 | 「共享单车停放点」 |
| 私有单车 | 「自行车停放点」或所在楼栋地下车库指定位置 |

### 私有单车按楼栋（硬性规定）

| 楼栋 | 必须停放位置 |
| --- | --- |
| 驾行楼、致用楼 | 致用楼地下停车库入口处指定位置（靠近实验楼电梯） |
| 修齐楼、治平楼 | 治平楼地下停车库内 224 号停车位指定区域（靠近教学楼电梯） |

### 违规区域（会被拖走）

路边、楼门口、消防通道、绿化带旁等一切非指定区域，都算违规停放。

## 车被拖走了怎么办

被拖走的车统一放在 **J1、J2 楼下的地下停车场**（靠东门的地下停车场入口那一片）。**不会有人通知，必须自己去找、自己领回。**

领回步骤：

1. 从靠东门的地下停车场入口进入 J1/J2 楼下地下停车场，在暂存区域找车。
2. 带证明材料：自行车牌、购车发票、车锁钥匙，或说清车辆特征（颜色、品牌、划痕/贴纸等）。
3. 领回后立刻规范停放——二次违规可能面临扣车、通报等更严处理。
4. 找不到就问教学楼附近的保安亭/值班室，他们最清楚情况。

## 自行车牌（重要前置动作）

私有自行车入学后要**尽快找辅导员统一办理自行车牌**。有牌才方便认领和管理，没牌被拖走后认车会非常麻烦。

## 回复风格要点

- 语气轻松直接，但「乱停会被真拖走」这一点必须强调到位。
- 常用一句话总结：办车牌 → 认准「共享单车停放点 / 自行车停放点」→ 停进去 → 省得被拖到 J1/J2 地下停车场还得自己跑一趟领回来。
- 用户只是问停哪时，不要长篇大论，先给判定结果，再补违规提醒。
