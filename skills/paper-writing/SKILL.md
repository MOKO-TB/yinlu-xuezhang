# 什么时候用

同学要写一篇论文(课程小论文、毕业论文、挑战杯/大创报告、评奖材料里的
研究综述),卡在**选题、结构、文献格式、查重**这几件事上。

# 先说清做什么、不做什么(这一条决定学长是不是在帮他)

**做**:把宽题收窄成能写的题;搭提纲并标出每节要回答什么问题;把**他自己
读过的文献**排成规范格式;把他写的段落和原文比对、指出哪几句像、给改写方向。

**不做**:**替他写正文**。他要「直接给我一篇 5000 字」时,说明做不了,并
给出能做的替代(先给三级提纲 + 每节的写作提示,他写完后逐段给他改)。
原因不是怕被发现,是**被查的是他本人**,代写把他直接推到学术不端上,代价远
比一篇慢一点、差一点的自己写的论文大。同理:

- **绝不编造文献**。他没给的作者/年份/卷期/页码/DOI,一律不出现;缺什么
  就在输出里写「【待补:页码】」并当面跟他说去哪查。编出来的参考文献是
  盲审老师最容易当场戳穿的一处,也是学术不端里最不好解释的一种。
- **不做"降重规避"**:不为了骗过查重系统而把话说错。改重要改得**仍然正确**;
  改了之后术语错了、数据变了,那就不叫降重,叫改错。

# 选题:三步收窄

1. **领域 → 问题**:让他先说"我感兴趣的课/新闻/经历",逼出**一句疑问句**
   ("为什么我们班的同学都不去图书馆地下一层?")。给不出疑问句就还没到选题。
2. **问题 → 切口**:加三个限定词把它做小 —— **对象**(哪个学校/年级/群体)、
   **时间/材料**(哪几年、有什么数据)、**角度**(只解释成因,还是评效果)。
3. **可行性三问**(必须逐条回答,不然到中期会卡死):数据拿得到吗?文献找得
   到吗(先让他真去查 3 篇并贴标题)?在剩下的时间里写得完吗?

写不出来的题直接说"这个题目你一个人做不完",并给一个更小的版本。

# 提纲:每节三件事

提纲不是标题堆叠。每一节给三行:**要回答的问题 / 需要的材料 / 字数预算**。

```
文科/调研类(总-分-总):
  1 引言:为什么值得问(现状+缺口)         ~12%
  2 文献综述:别人说到哪一步了(分组说,不逐篇罗列)  ~20%
  3 研究设计:我怎么看的数据/问卷/文本        ~13%
  4 发现与讨论:分 2-3 个小问题,每段一个论点     ~40%
  5 结论与局限:回答第 1 节的问题 + 承认不足      ~10%
  6 参考文献 + 附录(问卷原文)

实做/系统类(IMRaD):
  引言 → 相关工作 → 方法/设计 → 实验与结果 → 分析 → 结论与不足
```

综述最容易被写成"张三说了…李四说了…"流水账。改法:按**观点分组**,
同一组里再按时间排,末尾一句"这组研究共同缺的是…"。

# 参考文献:GB/T 7714 顺序编码制

正文按**首次出现顺序**编号 `[1]``[2]`,文末清单同序。类型标识:
`[M]` 专著 `[C]` 论文集 `[N]` 报纸 `[J]` 期刊 `[D]` 学位论文 `[R]` 报告
`[S]` 标准 `[DB]` 数据库 `[CP]` 计算机程序,联网补 `/OL`(如 `[J/OL]`)。

```
[序号] 作者. 题名[类型]. 出版地: 出版者, 出版年: 引文页码.        # 专著
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.                # 期刊
[序号] 作者. 题名[D]. 城市: 学校, 年.                            # 学位论文
[序号] 作者. 题名[N]. 报纸名, 出版日期(版次).                    # 报纸
[序号] 作者. 题名: 其他题名信息[EB/OL]. (更新或发布日期)[引用日期]. 获取和访问路径.
```

作者规则:1-3 位全列,用「,」分隔;**4 位及以上只列前 3 位,后加「, 等」**
(英文文献加「, et al」)。外籍作者按原文姓名,不加姓名称谓。

**渲染只走 stdlib,别手抄格式**(手敲几十条必然出现第 3 条少一个点号):

```python
# -*- coding: utf-8 -*-
import re

# 每条:{"type": "J|M|D|N|C|EB", 其余字段留空即视为“没给到”,输出【待补】
REFS = [
    {"type": "J", "authors": ["张三", "李四"], "title": "高校图书馆空间利用率调查",
     "source": "大学图书馆学报", "year": "2023", "vol": "41", "issue": "3",
     "pages": "55-63"},
    {"type": "D", "authors": ["王五"], "title": "本科生课外阅读行为研究",
     "pub_place": "广州", "school": "某某大学", "year": "2022"},
]

def _miss(v, label):
    return v if (v or "").strip() else f"【待补:{label}】"

def _authors(a):
    a = [x.strip() for x in (a or []) if (x or "").strip()]
    if not a:
        return "【待补:作者】"
    return "，".join(a[:3]) + ("，等" if len(a) > 3 else "")

def fmt(r, n):
    t = (r.get("type") or "").upper()
    A, TI = _authors(r.get("authors")), _miss(r.get("title"), "题名")
    if t == "J":
        tail = (f"{TI}[J]. {_miss(r.get('source'), '刊名')}, "
                f"{_miss(r.get('year'), '年')}")
        if r.get("vol") or r.get("issue"):
            tail += f", {r.get('vol', '')}({r.get('issue', '')})"
        return f"[{n}] {A}. {tail}: {_miss(r.get('pages'), '页码')}."
    if t == "D":
        return (f"[{n}] {A}. {TI}[D]. {_miss(r.get('pub_place'), '城市')}: "
                f"{_miss(r.get('school'), '学校')}, {_miss(r.get('year'), '年')}.")
    if t == "N":
        return (f"[{n}] {A}. {TI}[N]. {_miss(r.get('source'), '报纸名')}, "
                f"{_miss(r.get('date'), '出版日期(版次)')}.")
    if t == "EB":
        return (f"[{n}] {A}. {TI}[EB/OL]. "
                f"({_miss(r.get('pub_date'), '更新日期')})"
                f"[{_miss(r.get('cite_date'), '引用日期')}]. "
                f"{_miss(r.get('url'), '访问路径')}.")
    return (f"[{n}] {A}. {TI}[M]. {_miss(r.get('pub_place'), '出版地')}: "
            f"{_miss(r.get('publisher'), '出版者')}, "
            f"{_miss(r.get('year'), '年')}: {_miss(r.get('pages'), '页码')}.")

out = "\n".join(fmt(r, i) for i, r in enumerate(REFS, 1))
print(out)
print("\n注意:出现【待补】说明这位同学还没给到这个字段 —— 不要替他猜。")
```

# 降重自查:先量,再改

他给自己的段落 + 对照文本(他引的那篇原文/初稿),用 stdlib 算**连续重合片段**
和 n-gram 重合率。中文按字符滑窗,**不要按空格分词**(中文没空格)。

```python
# -*- coding: utf-8 -*-
import re
from difflib import SequenceMatcher

def norm(s):
    return re.sub(r"[\s，。、；：“”‘’（）《》【】—…\.\,\;\:\-\(\)\[\]\"']", "", s)

def overlap(a, b, n=8):
    """a 段与 b 文本的 n 字连续重合率 + 最长连续重合片段(≥15 字才报)。"""
    A, B = norm(a), norm(b)
    if len(A) < n or not B:
        return 0.0, ""
    ga = {A[i:i + n] for i in range(len(A) - n + 1)}
    gb = {B[i:i + n] for i in range(len(B) - n + 1)}
    rate = len(ga & gb) / len(ga)
    sm = SequenceMatcher(None, A, B, autojunk=False)
    best = max(sm.get_matching_blocks(), key=lambda x: x.size, default=None)
    frag = A[best.a:best.a + best.size] if best and best.size >= 15 else ""
    return rate, frag

para = "调查结果显示,图书馆地下一层的座位长期处于空置状态,而二楼则一座难求。"
src = "调查发现,图书馆地下一层的座位长期处于空置状态,而二楼则一座难求。"
rate, frag = overlap(para, src)
print(f"重合率 {rate:.0%}", "连续相同:" + frag if frag else "无 15 字以上连续相同")
# 只换了「调查发现 → 调查结果显示」也算高重合:开头结尾的整段照抄就会被报出来
```

汇报口径:逐段给「重合率 + 那串连续相同的话」,**不替他说好**;>30% 或
出现 15 字以上连续相同的,才值得改。改法按优先级给:

1. **合并/拆开**:两句并一句(用"因为/所以/也就是说"接),或把长句里的
   并列项拆成一句一句说。
2. **换主语视角**:"调查发现 X" → "我们在 3 月对 120 名学生的问卷里看到 X"。
   加了自家数据,重合自然就没了,而且这本来就是他自己该写的内容。
3. **术语解释重述**:保留术语原词,把术语**后面的解释**用自己的话说。

**别做的事**:同义词硬替换(查重系统专抓这个,且会把"信度"换成"可靠性"
把量表那一节说错)、改数字/单位/公式/法条/定义(改了就是错)、给他人观点
去掉了引用标注(从"像"变成"抄")。确实要保留原话的,加引号并注明出处,
这比压字数重要。

# 交稿前自查清单(读给他听)

- 题目里的问题,结论那一节回答了没有?
- 每个 `[n]` 在正文里出现过?正文里的 `[n]` 在清单里都有?编号连续?
- 有没有【待补】没填?(有就别交)
- 图表有没有编号和一句话说明?数据能不能对上正文里的那个数?
- 格式:学校模板的字号/行距/页边距/页眉,与参考文献要求的版式冲突时**按学校模板**。

# 坑

- 学校要求 GB/T 7714 **著者-出版年制**(正文"(张三, 2023)")时,上面
  `[n]` 那套不适用:字段一样,只是正文引注改成"作者, 年",文末按姓排序。
  动手前先问一句学校发的是哪份格式要求。
- 生成 docx 时中文字体要设 `eastAsia`(见 docx 技能),否则交上去是宋体。
- 中文标点与英文标点混在参考文献里最常见 —— 冒号、句点、逗号按 GB/T 用
  半角「. : ,」,题名内部的中文标点保留全角。
- 他贴来的"查重报告"里,系统给的红字**不一定真要改**(引用法条、公认定义
  标红是常态);按上面那条:该保留的加引号,而不是硬改。
