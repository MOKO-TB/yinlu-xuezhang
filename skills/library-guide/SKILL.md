# 图书馆导览(新生入馆教学模块)

「新建任务」下的固定功能模块:用户问任何图书馆相关问题时加载本技能,按下面固定套路回答。
数据全部**本地离线**(133 万条馆藏 + 真实楼宇数据),不联网、不等 OPAC 响应。
首页建议 chip 里的「图书馆自习座位怎么预约」「图书馆借还书规则是什么」就是本模块的入口。

## 一、功能说明(固定 4 项)

| # | 功能 | 用户这么问 | 怎么做 |
| --- | --- | --- | --- |
| 1 | **查馆藏** | 图书馆有没有《X》/ X 在哪个书库 / 余华的书有哪些 | 调 `library_search` 查本地库 |
| 2 | **找书导航** | 索书号 I247.5/868 在哪 / 文学类在几楼 | `library_search` 结果自带「楼层提示」;或 `library_guide(topic="floor", query="I")` |
| 3 | **逛馆导览** | 图书馆几层 / 自习座位多吗 / 有什么场馆 | 调 `library_guide(topic="space")` |
| 4 | **入馆流程教学** | 第一次去图书馆怎么借书 / 怎么开通借阅 | 调 `library_guide(topic="flow")` |

## 二、数据结构

### 2.1 馆藏库 `crawled/mfindgzyykj.libsp.cn/library.db`
SQLite 只读,约 1.3 GB(已 gitignore),**不要用 read_file 读**,只能经 `library_search` 或 sqlite 查询。

| 表 | 关键字段 |
| --- | --- |
| `books` | `record_id` `title` `author` `publisher` `isbn` `year` `class_no`(中图法) `call_no`(索书号) `abstract` `p_count` `onshelf` |
| `items` | `record_id` `call_no` `barcode` `location_name` `real_location` `process_type` `shelf_no` `in_date` |
| `locations` | `code` `name` |

字段语义:`p_count>0` 纸本、`=0` 电子书;`onshelf` 当前在架册数;`process_type` 取 `在架` / `借出-应还日期:YYYY-MM-DD` / `丢失`。
规模:书目 **1,331,774** 条(纸本 350,619 / 电子书 981,155),单册 **75,412** 册,覆盖 97,593 个分类号。

### 2.2 真实数据包 `skills/library-guide/data/library-facts.json`
本模块内置的楼宇/统计事实(由 `scripts/library_opac/make_guide_facts.py` 从上面的库生成,可重跑)。

| 字段 | 内容 |
| --- | --- |
| `catalog` | 馆藏规模统计 |
| `live_snapshot` | 抓取日单册状态:在架 75,041 / 借出 353(逾期 48)/ 丢失 18 |
| `class_distribution` | 22 个中图法大类的总/纸本/电子书种数 |
| `floor_guide` | 8 个藏书楼层(二楼—九楼)× 46 个书库/书墙(含册数与主类) |
| `class_floor_map` | 每个大类→楼层→具体书库 |
| `spaces` | 馆舍空间事实(官方来源,带 source) |
| `official_channels` | 官方系统入口 |
| `unverified` | **未取到官方口径的待补充项(禁止编造)** |
| `open_hours` `borrowing_rules` `seat_booking` `reader_card` | 人工补官方口径的槽位,现为 `null` |

### 2.3 常识条目 `kb/library-gzasc.json`
4 条图书馆常识(馆藏规模、分类分布、书库楼层分布、怎么找书),给 `search_knowledge` 用。

### 2.4 大批量书目 CSV `crawled/mfindgzyykj.libsp.cn/opac-catalog/`
要成批清单(整类导出/按类浏览)时用:`纸本_全量.csv`(35 万)与按大类拆分的 `纸本_<类号>_<类名>.csv`、`电子书_*.csv`。

## 三、调用方式

1. **查书**:`library_search(query="三体", top_k=8, kind="all")`。`query` 支持书名/作者/ISBN/中图法分类号;`kind` 取 `paper`(纸本,有馆藏地)/`ebook`/`all`。返回里带「楼层提示」,可直接答在哪层。
2. **查导览(楼层/空间/流程)**:`library_guide(topic="floor"|"space"|"flow"|"stats"|"all", query="I")`。`topic=floor` 时 `query` 传中图法大类字母或类名(`I`/`文学`/`TP312`);`topic="unverified"` 列出没有官方来源的待核实项。
3. **查楼宇/空间原始数据**:`read_file("skills/library-guide/data/library-facts.json")`,或 `grep(pattern="二楼", path="skills/library-guide/data/library-facts.json")` 精确取某层。
4. **查图书馆常识条目**:`search_knowledge(query="图书馆 馆藏 找书", top_k=3)`。
5. **省等待的纪律(重要)**:一次 `library_search` 通常就够答,**拿到结果立刻作答**,不要用同义词反复重查(实测反复重查会把 34 秒拖成 238 秒);查询词只用用户真实提到的书名/作者,不要臆造书名;中文书名不要翻译成外文重试。
6. **找书标准链路**:
   ① `library_search` 拿到书名、索书号、在架数 → ② 取索书号首字母(或 `class_no` 首位)得中图法大类 →
   ③ 查下方楼层表定位楼层与书库 → ④ 把「几楼、哪个书库、索书号、在架几册」一次说清。

## 四、使用示例

**例 1「图书馆有没有《三体》」**
`library_search(query="三体", kind="paper")` → 回:`《三体:图文版》刘慈欣著,索书号 I247.5/868,馆藏 2 册在架 2 册;I=文学,在二楼 201 文学新书区,按索书号找。`(据图书馆 OPAC 馆藏数据)

**例 2「文学类的书在几楼」**
查本表 I 行 → 「I 文学主要在**二楼 201 文学新书区**(9,378 册),另有部分在**三楼 301 流通书库**;人物传记也在二楼 213。」

**例 3「图书馆有几层、有什么」**
读 `spaces` → 「共九层,2022 年落成、2023 年 9 月 6—9 层投用;1—5 层阅览区总座位近 4000 个、很多靠窗还有单人隔间;6—9 层有艺术馆、非遗馆、科技馆、教师发展中心,能上天台;另有党建馆、咖啡吧、报告厅、小礼堂。」并注明来源为学校官方微信号。

**例 4「第一次去图书馆怎么借书」**
按固定流程讲(第五节),并给出官方入口;涉及册数/天数时说「以图书馆系统为准」,附 `official_channels`。

**例 5「图书馆自习座位怎么预约」**
**不编造**。如实说明:座位预约不在本馆 OPAC 数据范围内,官方入口见 `official_channels`,具体以图书馆通知为准;可补充 `spaces` 里真实的座位情况。

## 五、入馆流程(教学用固定步骤)

1. **先查有没有**:`library_search` 或在[师生图书服务平台](https://findgzyykj.libsp.cn/#/Home)检索,记下索书号与在架数。
2. **按楼层找书**:用上方楼层表定位大类所在楼层,再到具体书库按索书号顺序找。
3. **借还操作**:到自助借还机或服务台,凭校园卡办理;借阅记录在[图书馆借还书系统](https://lib.gzasc.edu.cn/)查。
4. **扩展用法**:电子书(库里 98 万种,`kind="ebook"`)、数据库资源、馆际互借/文献传递。

## 六、数据边界(必须遵守)

- **可放心引用**:馆藏统计、书库/楼层映射、索书号/在架数、馆舍空间、官方入口 —— 均为真实数据,引用时注明「据图书馆 OPAC 馆藏数据」并带抓取日期 2026-09-13。
- **禁止编造**:开馆时间钟点、可借册数/借期天数/续借次数、座位预约规则、办证流程。这些**没有官方来源**(图书馆站与 OPAC 都是 JS 门户,取不到),一律答「以图书馆官方为准」并给入口;`unverified` 字段列了每一项的原因与补法。
- **馆藏地可能为空**:纸本书目中仅 46,004 条(13.1%)抓到单册馆藏位置;为空只说明**未抓到位置**,不等于馆里没有——此时用「索书号→楼层表」给结论。
- **在架数是快照**:`live_snapshot` 是 2026-09-13 抓取的,不是实时;回答时说清「截至抓取日」。
- **电子书无纸本位置**:`p_count=0` 的是电子书,没有书库可去。

## 七、入口接入(新建任务)

模块已在「新建任务」首页挂了固定入口,三条路都能进:

1. **📚 图书馆导览 固定 chip**(`frontend/index.html` 的 `libChip`,与「🗺 打开校园地图」并列)。点一下自动发起首轮任务:「图书馆导览:带我走一遍从查书到借书的流程,顺便说说馆里有哪些自习空间」——用户不用想怎么问。
2. **动态建议 chip**:`minicode/suggestions.py` 的 `Topic("图书馆", ["图书馆","自习","借书","座位","占座"], "图书馆自习座位怎么预约", "图书馆借还书规则是什么")`,聊过图书馆相关话题后自动排到前面。
3. **直接提问**:用户自己问「图书馆有没有《X》」也会落到本模块。

- 技能放在 `skills/library-guide/`,`load_skills` 自动发现,系统提示词的「可用技能」清单里会出现 `library-guide`,模型按需 `use_skill` 读本文件。
- 要改首轮问法或再加固定入口:改 `frontend/index.html` 的 `libChip` 文案与点击分支即可,不用动数据。
- **正文超 8000 字符会被 `use_skill` 截断**,所以详细数据放 `data/library-facts.json`,本文件只留核心映射——扩充时沿用这个分工。
