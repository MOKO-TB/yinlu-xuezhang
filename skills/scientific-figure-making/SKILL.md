把一份数据变成一张能放进论文、报告或汇报的图。内核是 `references/figure_kit.py`(纯标准库手写 SVG,PNG 走 Pillow),设计口径抄自 figures4papers(ChenLiu-1996)的 scientific-figure-making 技能,并改成这个仓库里**真跑得起来**的版本。

# 什么时候用

- 同学要「出版级 / 论文里能用 / 汇报里能用」的图,或点名要 PNG / PDF / SVG、300 dpi;
- 分组柱、横条、热力图、折线、多面板组合;
- 明确说「照 figures4papers 那个风格」。

# 什么时候不用

- 交互式图表(Plotly / Altair / Bokeh)与网页可视化 —— 不做;
- 只是随手看个趋势、临时探索 —— 直接用 `render_chart` 就够,不必上这套;
- 3D、GIS、Illustrator / Figma 排版 —— 不做,直说做不了。

# 家族风格(照抄,别自己发挥)

- 配色只有一族(`PALETTE`):蓝=主方法/本方案,绿=增益/正向,红=对照/基线,灰=背景类别,金=全场唯一一处高亮。
- 去顶右边框,图例不压数据(放图外或单独一格)。
- 字号:大对比柱 24,紧凑子图 15~16;线宽:大柱 3,紧凑 2。
- 导出:矢量优先(SVG),PNG 只作预览;`dpi=300`(密集柱状图 600)。
- 多指标对比用**超宽画布**(宽:高 ≈ 3~4 : 1),别让柱子和标签挤成一团。

# 起步:把内核拷进你的脚本

内核在**技能目录**下的 `references/figure_kit.py`(不在工作区)。它是一份独立的纯标准库模块,用法是**整份拷进你的脚本顶部**,不是 `import`:

1. `glob` 找 `**/scientific-figure-making/references/figure_kit.py`,拿到真实路径(通常在应用的 `skills/` 下);
2. `read_file` 读它全文;
3. 在你自己的脚本里先粘这份内核,再粘下面的调用。

找不到内核时**照实说**「内核文件没找到」,然后按上面的家族风格手写 SVG —— 不要假装落了图。

# 起步调用(粘在内核后面)

```python
fig = Figure(width=1400, height=560, title="各方法的指标对比",
             source="数据来源: 哪个文件 / 哪次运行 / 哪个工具结果")
grouped_bars(fig.canvas, fig.box(0.06, 0.20, 0.58, 0.66),
             ["任务 A", "任务 B", "任务 C"],
             [[0.92, 0.88, 0.85], [0.85, 0.82, 0.88]],
             ["本方案", "基线"],
             ylabel="分数", annotate=True)
h_bars(fig.canvas, fig.box(0.72, 0.22, 0.24, 0.62),
       ["任务 A", "任务 B", "任务 C"], [0.92, 0.88, 0.85],
       xlabel="本方案得分", highlight={"任务 A"})
print(fig.save("figures/comparison"))     # 落 .svg,能落就再落一张 .png
```

# 四种常用图怎么选

- **分组柱** `grouped_bars`:几个方法在几个指标上的对比,最常用;
- **横条** `h_bars`:类别多、名字长,或想突出"谁最高"(传 `highlight={...}`);
- **热力图** `heatmap`:能力矩阵 / 相关性 / 覆盖度这类二维离散表,配 `LEVEL_COLORS`;
- **折线** `trend_lines`:随步数 / 时间的趋势,2~4 条为宜。

画完把文件路径回给同学;想在图里改配色就传 `colors=[...]`,改范围就传 `ylim=(lo, hi)`。

# 硬规矩(边界)

- **图上每个数字都要有来源**:`source=` 写清数据从哪来(哪个文件、哪次运行、哪个工具结果)。来源不明就不画,或明确标「示意」。
- **不补数**:缺失值不当 0、不插值、不脑补。少一个数就直接说缺哪个。
- **不做"看起来像图"的东西**:颜色、坐标轴、数值都要对应真数据;画不出来就直说做不了。
- **matplotlib 不在包里**:本项目打包明确排掉它,所以别写 `import matplotlib` —— 写了在装好的包里必炸。更复杂的图(雷达图、3D、地图)先说明这套内核做不了,再问同学要不要换工具。
- **PNG 是可选**:没装 Pillow 或找不到中文字体时只落 SVG,把原因说出来,别静默少一个文件。
