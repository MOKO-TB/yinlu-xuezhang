# 引路学长

一个运行在 Windows 桌面的编程引路智能体——**图形界面**里交任务,它自己读代码、改文件、跑命令,直到把事情做完;像学长带学弟一样,动手前讲思路,关键处给理由。附赠同核引擎的终端版。

## 功能

- **桌面 GUI**:玻璃拟态风(**浅色=校园日景航拍、深色=同一校园的暮色航拍**,切主题即换景;侧栏/顶栏/气泡/工具卡都是磨砂玻璃层),深色/浅色一键切换;会话列表、Markdown 流式对话;**思考与工具调用收成一条可折叠的「工作过程」**(最终回复开始时自动收起,点标题行展开回看);**划词即弹「复制选区」**,消息右键有原生菜单(撤销/剪切/复制/粘贴/全选),Ctrl+C/V/X/A 正常可用
- **撞到上下文超限会自己救一次(v0.9.143)**:以前端点回一句「太长了」,这轮就以一句模型报错收场(命令行那边还是退出码 1),看着像程序坏了 —— 而窗口是量出来的,超了压一压真能过去。现在:认得出是超限、且**确实压动了**,就就地压缩一次再发这一发请求,**只有一次机会**(第二次还超限就照实失败,不拿有损压缩换一次次白等);认不出是超限就一个字都不压(参数写错的 400 与超长的 400 是同一个状态码,认错一次的代价是把不该压的对话压掉了);压了会在对话里留一句人话说明,不静默改你的上下文
- **不会配模型?开「智能配置」(v0.9.142)**:「编辑模型配置」顶上那颗开关。开着的时候,下面那些输入框整块灰掉(不消失、不清空),上面一行摊开写着「窗口 1,000,000 · 图片输入:支持 · 推理档位:default/low/high · 最大输出不限制」,并标清楚这个数是**这台机器探测出来的**还是**内置目录里的**。语义是**整份声明让位**而不是逐键 —— 混着读会造出一个没人能解释的模型;关掉开关逐字回到你自己填的那一份。目录里没有、也没探测过的模型,那一行是警告色并明说「不知道,建议先点一次测试或自己填」——凭空显示一个窗口数,等于把「不会配」换成「配错了还不知道」。默认全关:今天每一份配置都不该被这次升级改掉
- **出站网址策略(v0.9.141)**:`config.json` 里 `net_policy` 三档 —— `off`(默认,与今天逐字一样)、`ask`(模型要访问不在你 `allow` 名单里的域时**问一次**,每步重新问、不给永久免确认,`full` 档也问)、`deny`(直接拒)。`allow`/`deny` 写主机名,支持 `*.school.edu` 这种后缀,而 `evil-school.edu.cn` **命不中** `*.school.edu`(边界处必须有个点);同一条域既 allow 又 deny 时 deny 赢。管的范围说死:`web_crawl` / `page_parse` / `browser_open` 这三条模型能自己填网址的路 ——**它是策略不是沙箱**,`bash` 里的 curl、你配置的模型/MCP/天气/通知端点、页面自己的子请求都不在它范围内;真要「这台机器只能连这几个域」得靠操作系统层(S5c,本项目还没做,欠账登记在 HANDOFF §6 52)
- **回答流出来不卡(v0.9.140)**:以前模型每吐一个字,程序就单独往窗口里搬一次 —— 量出来的结果是 600 个增量要 1715 ms 全花在这趟往返上(同样的内容放进**一次**调用里循环只要 5.7 ms)。现在流式增量攒成一批送(600 次往返 → 18 次),相邻同类型的还合成一条;两只兜底是这一笔的关键:**一只 80 毫秒的定时器**保证"模型说半句停三秒"时那半句照样上屏(不然省下的往返会变成新的卡顿),而**任何非增量事件先冲缓冲再送**(工具卡、确认框永远不插在正文中间)。停止与关窗也各有一次 flush,最后那半句不会留在缓冲区里
- **模型在想什么,看得见也收得起来(v0.9.138)**:外层「工作过程」折叠的是整条过程,里层「💭 思考」**自己也能点开/收起** —— 思考中默认摊开,旁边一行实时写着「思考中 N 秒 · 约 X token/秒」。那个「约」是认真的:token 数要等服务端回报才准,在那之前只能按字数估,所以答完之后下方那行 ⚡ 才是实测值,**两行不是一回事,不拿估算冒充实测**
- **后台任务**:新建任务 / 切换会话都**不会打断**正在跑的任务——每个会话有自己的运行器(独立 Agent 与会话上下文),旧任务转后台继续跑完;侧栏对应会话显示转圈与「运行中」,点它即可切回去看实时进度(模型、MCP 连接、沙箱策略在会话间共享,多开一个会话不会重复起进程)
- **内置校园模型,开箱即用**:固定使用广州应用科技学院内网模型服务(`deepseek-v4-flash`),不需要填 API Key,界面也不提供模型切换入口(顶栏模型标识只展示;内网地址与 Key 都不下发前端)。**模型的上下文窗口与「是否支持视觉」由程序启动时自动向服务探测**(结论缓存一周),任务面板标签与压缩触发阈值据此自动对齐 —— 学校换模型/换网关不必改代码
- **工作区(自己选文件夹)**:顶栏「📁 工作区」胶囊点开就能挑一个文件夹当 Agent 的工作台——读写围栏、附件 `uploads/`、计划 `plans/`、长期记忆 `memory/`、**超长工具输出的转存 `tool-outputs/`**(v0.9.126:某一步输出超过 `max_output_chars` 时,头部照旧、尾巴落在这里,回话点名路径,模型要接着看就 `read_file`,不必重跑那一步;对外/网页版关掉它,因为工作区目录是访客共用的)全部落在那个文件夹里;弹窗列出当前/默认与最近用过的 8 个(可一键移出列表,只动记录不删文件夹),「选择文件夹…」走系统原生对话框。CLI 用 `/workspace <路径>` 或启动参数 `--workspace` 拿到同一份记忆(详见「工作区」一节)
- **跑着的时候能补一句**(v0.9.127,v0.9.138 改成可反悔的草稿):这一轮正在转时按 Enter 不是"发第二条任务",那句话先落在输入框上方一条 `↳ …` **草稿**上,旁边三颗:「↵ 插话」才真的并进这一轮、「✎」拿回输入框改、「🗑」丢掉。以前是按下去立刻塞进正在跑的那一轮 —— 打错一个字也没有反悔的余地,而它已经按那句去取下一步了。句子进了信箱之后仍是在**下一个安全边界**(某一步跑完、下一次请求发出之前)并入,模型读到的是「它答到哪儿 → 你补的那句 → 接着答」。**不停下来打断正在跑的那一步**:`tool_call` 与结果必须成对,从中间插一条用户消息就会留下悬空对儿(那表现是从这一轮起每次请求都 400)。**按停止不会吃掉你打出去的字**:没读完的话留在信箱,下一问开头读到;换会话则不留残草稿。带附件那句当场拒(图要先拼进消息体,那一步只在开新回合时做),排到顶也当场说并原样退回输入框。**命令行没做**:它正卡在 `input()` 上等一句完整的话,没有后台读线程 —— 这条差别是形态的限制,不是漏实现,所以别拿"CLI 也能插话"去写交付说明。
- **同一条消息里的多只工具会一起跑**(v0.9.126,补齐竞品那一格):模型一次要三个 grep/读文件,不再一个等一个。**只有名单内、只读、没配钩子、且门不会为它开口的那几步**才进线程池(资格表与逐条理由在 `minicode/tools/concurrency.py`);确认框、留档顺序、失败连击这些一律留在主线程按模型给的顺序走。**`ask_user` 与浏览器那几只刻意不在名单里**——前者弹框发生在 handler 里(从工作线程弹框是不报错的坏法),后者共用一条 CDP 会话。
- **数学公式排得出真式子(v0.9.138)**:回答里的 `$…$`、`$$…$$`、`\\(…\\)`、`\\[…\\]` 由内置 **KaTeX**(离线,不联网)排版。两处刻意**不**当公式:代码块与行内代码里的 `$`(那是用户要照抄的原文)、以及「报名费 $5 和材料费 $10」这种价格(判据与 remark-math 同一条:内容首尾不许空白、闭合 `$` 后不许紧跟数字)。公式在交给 markdown **之前**先抱出来 —— 否则 `$s_1$ 与 $s_2$` 中间那对下划线会被 markdown 当成斜体吃掉,再抱就拼不回来了。某条式子解不开时屏上留的是它的**原文**,不是一片空白,也不是一句报错。
- **侧栏的任务能改名、能归档(v0.9.138)**:悬停在某条历史上出现「⋯」(或直接右键那一行)→ 打开 / **重命名** / 归档 / 取消归档 / 复制会话 ID / 删除。重命名是**就地编辑**而不是弹 `window.prompt`(内嵌 WebView 里那种对话框可能压根不出现,用户看到的就是"点了没反应");写回的是留档开头那行 `session_start` 的 `title`,与 CLI 的 `/rename` **同一只手**,所以两边不会一个能改一个不能改。归档的口径没变:**沉底 + 打标,不删不隐藏**(侧栏、`/resume`、分支审查共用一份序号,一隐藏就把别人的坐标弄破)。
- **分享图能直接粘(v0.9.138)**:🖼 排完卡片之后,旁边那颗 📋 把**刚生成的那一张**复制进 Windows 剪贴板(CF_DIB),到微信/文档里直接 Ctrl+V,不用再翻工作区 `images/`。门面那颗**零参数** —— 路径由桥自己记着,界面传不进路径,也就传不进 `..\` 指向的任意文件;剪贴板被别的程序占着时它照实说一句,不假装复制成功。
- **预估费用按各家官方页算(v0.9.138)**:`global:deepseek-v4.1-flash` 这类带命名空间/展示前缀的名字现在认得出来了(从前明明有价却报「未知」—— 有价说成没价与没价说成 $0 是同一类坏法的两半);但**不并档**,`qwen3.8-flash-pro` 不许落进 flash 那一行(并档就是贵的那档按便宜的价报,而报出来还是个看着很精确的数)。人民币报价的按 `¥` 列、美元报价的按 `$` 列,**合计也分币种各列一个数** —— 折成一个数要引入一个凭空编的汇率。单价悬停那句写着**来源与核对日期**,官方有峰谷两档时写明取的是哪一档。价目缺行的模型照实进脚注「未标价(没算进总数,不是 $0)」;要补价:`pricing-override.json`。
- **沙箱边界**:工作区内的路径直接放行、工作区外逐次确认、`~/.yinluxs` `~/.ssh` 等敏感目录永远拒之门外;还能禁网命令、加自定义禁配规则、卡命令超时;GUI 顶栏一键开关(详见「沙箱」一节)

- **本地知识库检索**:`kb/` 目录放 JSON 资料库(校园通知、经验库等,自带 credibility 可信度分级与来源网址),`search_knowledge` 工具按 中文 2-gram 打分检索(标题×3+标签×2+正文×1),回答引用时输出来源网址供用户核实,非 A 级数据强制标注"未经核实";**未命中时工具回话自带下一步**(v0.9.92:用 web_search 联网查证并附来源、查到有长期价值的内容征得同意后 kb_suggest 入库、纯常识不必联网)—— "未命中就联网"从技能里的自觉变成工具回话里每次都在的路径

- **没读过的文件先问一句(v0.9.133)**:要改的是一份**既有文件**而这个会话还没读过它 → 确认框多一句「学长手上没有它现在的内容,要替换的那段是按印象写的概率不低」(点「允许」照改,点「拒绝」就先 `read_file`)。这不是安全门,是**正确性**门:模型没读过就改,`edit_file` 的逐字匹配要么白烧一轮、要么把错的永久写进你的文件(Claude Code 把这当防幻觉第一道)。四条例子内定好了:**自己刚写出去的文件不算没读过**(那份内容就是它写的)、**新建文件不出声**(没有可先读的东西)、**读失败不算读过**(二进制/编码/越界那几种,判据用的是"内容真进过它的手"而不是"调过一次工具");这本账**跟着每个 agent 自己走**——子代理各自一份,侦察那一档读过的不替写代码的那档以为它也读过(它拿到的是摘要)。只在**还会问人**的两个档位生效:`变更前确认` 给本来就有的那张框补一句原因,`自动编辑` 把「工作区内写文件自动放行」改成「没读过的先问一句」;`自动放行` 与 `完全访问` 不动 —— 那两档对用户的承诺就是不再问,拿一枚启发式去拆承诺是另一种坏法。不想要了:`config.json` 里 `read_before_edit: false`,行为逐字回到以前
- **`/undo` 回滚**(CLI):写前快照;`/undo` 先列这一轮改过的每一处(编号/改还是新建/退下去是恢复还是删除/有没有被别的工具二次动过),`/undo diff <编号>` 看「改之前 vs 磁盘上现在」,真要退是 `/undo <编号>`·`/undo last`·`/undo all` 三种,都会先摆出这一处再问 y/n —— 没答就算拒绝,磁盘一个字不动

- **模型层收口**(v0.9.40):模型"看到的东西"这一层补了四个口子。**①时钟**——日期与课表是建会话时烧进 system prompt 的,而本应用是托盘常驻的:进程连着开三天,它会照第一天的日子念三天。现在每个回合开始前对一次表,**跨天了才**把提示词重算一遍(走 `build_system_prompt` 同一个函数,不出现第二份时间来源;一天至多破一次 KV Cache),并说一句「已跨天,日期与课表已刷新」。**②压缩**——超长历史折叠成摘要时从「保尾丢头」改成**留头 + 留尾**(总预算 40000 字不变),摘要提示词按校园场景重写:任务目标 / 改过哪些文件 / **日期·课名·地点·待办·来源网址** / 关键决定 / 下一步。**③尺子**——压缩阈值以前只数消息,而每次请求实际还带着 40 来个工具的 JSON Schema(几千 token),于是面板说"还早"它却突然压;现在 `Agent.context_tokens()` 一处算清,任务面板、`/history`、触发器三处同一个数。**④步数**——`max_steps` 进 config(默认 40,老 config 行为不变),撞上限后不再戛然而止:补一次**不带工具**的调用,让模型就着已经跑完的那些步骤写「已完成 / 未完成 / 下一步」,那一句「工具用完了」只活在这次请求里、不进留档;这次调用失败就静默退回旧行为
- **记起上次 + 就地改答**(v0.9.41):`search_history` 工具 / CLI `/find` / 侧栏搜索框是**同一份算法的三个消费者**,而留档在 `APP_DIR/sessions`(工作区围栏之外),所以模型侧走的是受控出口 `session.history_hits`——只取用户与助手正文(工具往返不进结果)、只给会话时间与工作区目录名、绝对路径不下发,网页版明确排除并写了理由。回答下面 👍/👎 旁多一颗 **↻ 重新生成**:撤掉这段答复、照原样重跑那句提问(不复用「编辑重发」那条路,因为它会丢掉当时那张图);点过的 👎 仍留着,那是差评回灌要的信号。
- **四处静默失效补闸**(v0.9.41):**悬空工具调用**——`add_assistant`(带 `tool_calls`)与逐条 `add_tool_result` 不在一个事务里,断电/强关/压缩"保头+尾"任一种切断都会留下"喊了工具没结果"的序列,端点对它回 400 且**往后每轮都 400**,用户只剩 `/clear`;现在在恢复时、工具循环异常时、以及**贴着出口** `_messages_for_request` 三处补齐,原始留档不回写只补一行 `repaired` 标记。**技能引用的工具名**钉成清单(改名/删除红,技能新依赖一个工具也红)。**技能要用的库**(`pptx/docx/openpyxl/pypdf`)以前只在打包清单里、`requirements.txt` 一个没声明,源码用户跑论文/课件技能第一步就 `ModuleNotFoundError` 而所有测试全绿;现在两头都钉。**模型连不上**从前是死胡同(一句「模型调用失败」之后没有任何恢复信号),现在失败起一条只问 `GET /models` 的探活(60 s × 最多 10 次,不动 Key 额度),通了在聊天里说一句并尽力弹一条桌面通知,同时**那句没送出去的话回到输入框**——绝不自动重发。
- **首页会看进度 + 能发群的卡片**(v0.9.42):**「接着做」那一行**读的是真状态(逾期/今天要交的待办、计划里标「进行中」或现在能动的那一步),三样都没有就整行不出现,点一下只把话填进输入框不自动发。**🖼 分享图**把一段回答排成能直接发群的竖版卡片 PNG 存进 `images/`,回答里出现过的链接自动写进卡片尾部「来源(可点开核实)」,没有链接就不放这一段、超长会明说"只排到这里"。**Ctrl+F 会话内搜索**:两个以上字起搜,报"第几条 / 共几条",命中在收起的「工作过程」里会自动展开;高亮走 CSS Custom Highlight API,**不改 DOM**(重写 innerHTML 会把消息上的复制/编辑/↻ 按钮事件全弄丢)。快捷键补齐:`Ctrl+Shift+K` 聚焦输入框、`Ctrl+Shift+[ / ]` 切会话。工作区弹窗里三个"只进不出"的目录(`uploads/`、`images/`、`charts/`)看得见大小也删得掉。
- **网页抓取**:`web_crawl` 抓网页/整站为 markdown(同域 BFS 跟链、限页限速),入库前自动去掉每页重复的导航/页脚;可选 to_kb 一键写入本地知识库 `kb/crawl-<域名>.json`,用 `kb_category`/`kb_tags` 打主题标签(检索时标签权重×2),由 search_knowledge 带来源网址检索。源码环境用 crawl4ai(真浏览器,能渲染 JS);**打包版自动切到内置轻量抓取器(httpx + BeautifulSoup)**,不带浏览器内核(否则 79MB 的包会涨到约 500MB),静态站点效果一致,需要 JS 的页面会明确提示(或改用下面的浏览器能力)
- **浏览器能力(CDP 直连,不背浏览器内核)**:给 agent 装上"眼睛"——它能真的开一个浏览器看页面,而不只能抓静态 HTML。`browser_open` 返回 **JS 渲染完成后**的标题与正文(教务/通知页这类靠 JS 渲染的站点终于是真内容);`browser_eval` 在页面里跑一段 JS 精确取数(价格/表格/链接列表)或点按钮、滚动;**页面交互三件套**:`browser_snapshot` 列出页面上所有可见可交互元素(链接/按钮/输入框/下拉框,带序号与字段名,只读不弹确认),`browser_click` 按快照序号/按钮文字/CSS 选择器点击并自动回报点击后的页面状态(序号是 snapshot 在页面元素上打的临时标记——页面一变标记就失效,**永远不会点错元素**;页面上有多个同名按钮时拒绝盲点),`browser_fill` 按字段名批量填表单(name/id/占位符/aria/标签文字都认,下拉框按选项文字匹配、勾选框接受 true/false),文本框用「原生 setter + input/change 事件」写入——React/Vue 的受控组件也能感知到变化;可选 `submit=true` 全部填好后自动点提交,任何字段失败都不会提交半张表单;`browser_screenshot` 把页面截成 PNG 存进工作区,**图直接出现在对话里**(点图可放大);`browser_close` 收标签页。两条接入路线:**launch**(默认,零配置:自己找 Edge/Chrome 用独立 profile 起一个无窗口实例)与 **attach**(连用户自己开了远程调试的浏览器,**带他的登录态**,能看只看得到登录用户的页面)。**attach 只在显式 `mode="attach"` 或设了 `YINLUXS_CDP_URL` 时才用**——默认不动用户那个有几十个标签页和真实登录态的浏览器,对分发型程序太侵入,实测也更容易卡住(所以 auto 探到调试端口也会先走 launch,只有本机起不了浏览器时才拿 attach 兜底)。attach 的探测要**三级兜底**:`127.0.0.1:<port>/json/version` → `localhost:<port>` → **直接读用户目录里的 `DevToolsActivePort` 文件第二行**;实测本机 Edge 153 对 `/json/*` 一律返回 404,只有文件里那条 ws 路径连得上,只依赖 HTTP 探测就会永远报"没找到开着远程调试的浏览器"。且**探到端口不等于能用**(残留文件/端口被别的程序占),要真跑一次 `Browser.getVersion` 握手才算成立。靠纯 Python 的 `websockets` 说 CDP,所以轻量版安装包**不**需要 playwright 与 270MB 内核。安全三条:只允许 http/https(`file://`、`javascript:`、`chrome://` 一律拒);每个线程/会话/子代理**各自一个标签页**,并发不串台,已结束线程留下的页会被回收;网页版(对外只读)**不给浏览器工具**(可被用来打内网 + 在服务器上起浏览器)。终端 `/browser` 看当前能不能用、走的哪条路线。**标签页可见可管(v0.9.98)**:`browser_status` 会列出现在开着哪些页(标题/网址/归属/编号),`browser_close` 带 target=编号能关任意一路的页(用户自己开着的页只脱手不关)。**配置被占用不再是死结(v0.9.139)**:上一次导入留下的浏览器还占着 `browser-profile` 时,再点「打开登录页」以前只会报一句「Edge 启动后立刻退出(退出码 0),无法启用浏览器能力」,点多少次「再读一次」都是同一句 —— 现在先**复用**那个活着且端口答得上来的实例(一个进程都不起),要窗口(教务登录必须有)而复用的那个是无窗口的就**换一份兄弟配置**继续并明说「教务要重新登录一次,登录态不会跟过来」,全起不来才报错、且那句话带着退出码与三条出路。四条保守口径:没有我们的实例标记就不复用(不知道那个实例有没有窗口,拿它做必须看得见的登录是在赌)、`YINLUXS_BROWSER_PROFILE` 点名的目录绝不换(换目录等于绕过用户显式挑的那本登录态)、**绝不 taskkill 不是自己起的进程**(要关一个复用来的实例走它自己的 `Browser.close`)、收工时只清自己那一份标记(删掉别人刚写的等于骗下一个人「这份配置没人用」)

**无头模式那条**是给脚本用的,不是给人看的:`--json`(等价 `--output-format json`)把横幅、
进度、工具卡片全部改道 stderr,stdout 只留一份能 `json.loads` 的结果(`response` / `tool_calls`
/ `asks_refused` / `turn_tokens` / `session_file` / `status` …)。退出码
**0 做成 · 1 模型报错 · 2 参数不对 · 3 该问人却没人可问 · 4 被上限收尾 · 5 中断**。
第 3 码是这条路上的安全边界:**换入口不换权限** —— confirm 档该弹框的步骤,无头模式一律
按"不点头"处理并把它说出来(文件不会被写出来),而不是替你批一次从此不问。
`--output-format` 认不出的值直接报错,不静默退回纯文本。
- **要过程可判就上事件流(v0.9.144)**:`--output-format stream-json` 让 stdout 变成一行一条的
  NDJSON:第一行 `stream_start`、中间是 `text_delta` / `reasoning_delta` / `tool_start` /
  `tool_done` / `hard_reject` / `compacted` / `retry`,最后一行是与 `--json` **同构**的
  `result`。每条都带从 1 起严格递增的 `seq`,每行立刻 flush;人读的话(`info` / `error` /
  进度)仍旧只走 stderr。它面向的读者是**把学长当子进程驱动的编排层**(CI、外层 agent),
  不是盯着日志看的人,所以**不新增退出码**、结局仍以最后那份结果对象为准。`--json` 与它
  **互斥**(两个一起给报参数错,靠位置决定形状是这类旗标最贵的坏法);`--output-schema`
  与它**可以一起用**,那时格式仍是事件流,`structured_output` 只出现在 `result` 行里。
  stdout 被下游关掉(管道关闭)按中断处理,退出码 5,且停发后续事件。
- **要一份结构化结果(v0.9.136)**:`--output-schema <内联 JSON 或文件路径>` 让模型按你给的
  JSON Schema 只输出一个 JSON 对象,结果里多两个固定字段:`structured_output`(**按 schema 验
  过了**的值,不合就是 null)与 `schema_violations`(人话清单,每条带路径如 `notes[1]:类型应是
  string`)。给了这个旗标就自动按 JSON 出(那份结果本来就是给机器读的)。**这一条做的是"问过
  它 + 验回来",不是网关侧的受约束解码** —— 后者能**保证**模型只能吐出合 schema 的字节,我们
  不知道接的这家端点支不支持,所以只保证"不合就明说"(退出码 6,与 `status: schema_violation`
  同一条)。把前者说成后者,就是这一路最容易犯的"界面上说安全、实际没拦"。schema 里**影响
  合法性判定的关键字这一版验不了就当场拒收**(`anyOf` 有、`$ref`/`pattern`/`patternProperties`/
  `minimum`/`minItems`/`not` 无),而不是默默忽略 —— 忽略一条 = "我按 schema 验过了"成了假话;
  `description`/`title`/`default` 这些不影响判定的元数据可以随便写。schema 读不出来就在**进
  Agent 之前**以退出码 2 退,不花那一轮额度。那句输出要求走系统侧、只活这一回合,**不并进
  用户原话**(否则它会进留档、被「编辑重发」原样带回、被 `/history` 念出来 —— 机器加的
  东西不该冒充人话)。
**第一次运行例外**:全新安装还没有 `config.json` 时,CLI 会先从模板生成它并以退出码 1 结束
(就是那句"直接重新启动即可")—— 这是 CLI 一直以来的首启行为,无头模式不绕过它;第二次起才是上面那套契约。

- **模型自带一份配置(v0.9.130)**:模型管理里每个模型有一颗「配置」,能填上下文窗口、最大输出 Token、图片输入(支持/不支持/跟随探测)、推理等级清单与参数映射。**填了的数真的生效** —— 窗口决定什么时候压缩、最大输出决定请求里的 `max_tokens`、等级决定 🧠 按钮那几个选项怎么编码进请求;留空的项一个字都不覆盖(探测与内置目录照旧)。优先级是**声明 > 探测 > 内置目录**,所以「我这家的模型明明支持图、探测说没有」这种情况可以自己定。只填了等级没写映射会被拒绝保存 —— 那几档会显示在按钮上却一个参数都发不出去,那是摆设。
- **改动前像落盘(v0.9.131)**:`/undo`、`/rewind`、「本轮改动」逐文件回退那本账以前只在内存里,所以「改完三个文件、程序崩了或重启,回来清单是空的、磁盘却还是改过的样子」会真发生。现在每处改动的**改之前原文**按会话落在本机 `checkpoints/`(工具还没跑就先写,所以写到一半崩了也在)。一条硬规矩:**存不下的就整条不记** —— 因为「没有前像」在回退端的含义是「这文件当时不存在」,按那个含义退会**删掉你现在的文件**,所以宁可清单少一条,也不留一条假前像。这份账本**不进安装包、不进迁移包**(里面是别人文件改之前的原文),会话留档被删时它跟着被扫掉。

CLI 命令:`/help` `/clear` `/model`(供应商列表)`/history` `/resume [<n>]` `/find、/rename、/archive、/unarchive、/fork [<关键词>]`(搜自己的历史会话)`/undo`(清单;`diff <编号>` 看改动、`<编号>`·`last`·`all` 才动手,动手都要点头)`/compact`
`/sandbox` `/permission [档位]`(四档权限 + 项目白名单生不生效)`/think [档位]`(思考档位)`/instructions`(这一轮读到了哪几层指令:内置 + 用户级 + 项目级,各几行、有没有被截)`/rewind <第几问> [files|talk|both]`(退到那一问之前:文件与对话一起退,默认 both;留档不删)`/snapshots`(影子库里有哪几次整树检查点)`/restore <序号>`(还原到那次快照,**只还原、绝不删** —— H,v0.9.157)`/workspace [路径|default]` `/memory` `/remember` `/dream` `/skills` `/kb`(知识库统计)`/plan`

`Ctrl+C` 中断当前回合。

## 网页版(校园助手)

同学打开网址就能用,不用装任何东西。**只读问答**:校园知识库 / 图书馆馆藏 / 校园地图 / 技能说明,没有文件与命令能力。

```bash
python web_main.py                  # 默认监听 0.0.0.0:8480,同学从校园网访问
python web_main.py --open            # 顺带用本机浏览器打开
python web_main.py --host 127.0.0.1  # 只给自己用
python main.py --web                 # 等价入口
```

- **同一套前端**:`frontend/index.html` 一行不改 —— 桥接 shim `frontend/bridge-web.js` 在服务时注入,把 `pywebview.api` 换成 `POST /api/<方法>`,把引擎事件用 SSE(`GET /api/events`)送到页面。
- **引擎零改动**:`agent.py` / `llm.py` / `tools/*` / `sandbox.py` / `session.py` 全部原样复用;新增的只有 `web_ui.py`(队列推送)、`web_profile.py`(白名单与门面)、`web_server.py`(HTTP/SSE)。
- **只读白名单**:`web_profile.PUBLIC_TOOLS` 显式列举(frozenset),**不用 `Tool.read_only` 过滤** —— 那个标志的语义是"执行前不需要确认",不是"读不到敏感数据"(`read_file`/`grep` 都是 `read_only=True`,而工作区里就有含内置 Key 的 `config.local.json`)。
- **多访客隔离**:每个浏览器一个 cookie 身份,各自的会话、Agent、事件队列与留档目录(`web-sessions/<id>/`),互相看不到对方的对话。
- **滥用控制**:每访客 12 次/分钟、全局同时 3 个回合(超了回"前面还有 N 位同学")、每日 2000 次上限;发问与来源 IP 记在 `web-usage.log`。
- **跨站防护**:校验 `Origin`/`Referer` 与 `Host` 同源 —— 否则你浏览器里任意网站都能朝这台服务器发请求。
- **部署注意**:服务必须跑在**能访问校园内网模型端点**的机器上(公网云主机连不通 `10.x`);监听非本机地址时,同网段任何人都能用本服务并消耗学校模型额度。只读白名单下没有 shell,但请勿把非只读版本开到公网。

更完整的设计与安全取舍见 `D:\game\agent网页版-实施方案.md`;开发时看效果可用 `py -3.12 _tmp_dev_check/serve_web_e2e.py --port 8481`(带一个本地假模型,不连校园网)。

系统提示词会列出可用技能,模型接到相关任务时自动用 `use_skill` 读取全文后再行动。CLI 用 `/skills` 查看已装技能。

## 沙箱

Agent 能碰到什么,由四层边界决定:

| 边界 | 行为 |
|---|---|
| 敏感路径(`~/.yinluxs`、`~/.ssh`、`~/.aws`、`~/.gnupg` …) | **永远拒绝**,任何权限模式、任何用户授权都不能越过 |
| 工作区内路径 | 直接放行 |
| 工作区外路径 | 默认**逐次确认**;用户放行后本回合内有效;`allow_outside_workspace: true` 则直接放行 |
| 脚本内容(v0.9.39 起) | `py_script` / `bash python x.py` 要跑的文件先按行扫一遍(只扫前 200KB),把**命中的那几行原文 + 行号**摆进确认框,分「碰密钥位置 / 走出工作区 / 要联网或再起子进程」三类 |

命令侧:灾难命令照旧硬拒绝(`rm -rf /`、`format c:`、fork 炸弹…);沙箱还支持
`allow_network: false` 禁掉 curl/wget/ssh 等联网命令、`deny_patterns` 加自定义正则
(如 `git push`)、`timeout_seconds` 收紧命令执行超时上限。
子进程这边另有一层:环境变量里名字像凭据的(`*_API_KEY`、`TOKEN`、`SECRET` …)默认摘掉,
摘了哪几个会在输出末尾告诉你;不想摘就设 `sandbox.strip_env_secrets: false`。
**边界要说得出自己拦不住什么**:脚本内容级扫描只负责"把可疑行摆到你面前",不给子进程做隔离;
`allow_network` 是按命令名 / 脚本导入扫的门禁,**不是操作系统防火墙** —— 真要断网得用虚拟机级隔离。

GUI 顶栏的「🛡 沙箱开/关」可随时切换(写回 config.json);CLI 用 `/sandbox [on|off]` 查看或临时切换。
注意:**沙箱边界优先于权限模式**——`accept_all` 也不能让 Agent 在没有确认的情况下访问工作区外。
**档位越高越信任你,不是越信任外面来的东西**:要密钥的脚本、访问凭据目录的脚本、扫出外传出口的脚本,
**在 `full` 档也一样弹确认**。
沙箱判的「工作区」就是「工作区」那一节选定的文件夹:**换工作区,围栏跟着换**,
且切换时会清掉本回合已放行的工作区外路径(不把旧授权带到新工作区)。

## 工作区

**Agent 在哪个文件夹里干活,由你定。**

| 入口 | 说明 |
|---|---|
| GUI 顶栏「📁 工作区」 | 弹窗里选:当前 / 默认 / 最近用过;点一行即切过去 |
| CLI `/workspace` | 无参=查看当前与最近;`/workspace <文件夹路径>`=切换;`/workspace default`=回默认 |
| CLI 启动参数 | `--workspace "D:\我的资料"` / `-w`(也可写 `--workspace=...`) |

- **默认工作区** = 程序目录(exe 旁 / 开发态仓库根),也就是改造前写死的那个,老用户无感。
- **只接受已存在的文件夹**:不做隐式创建(免得在用户盘上凭空长出目录);
  `~/.yinluxs`、`~/.ssh`、系统凭据目录这类放钥匙的地方**永远不能**当工作区。
- **切换的代价说清楚**:旧会话运行器一律停掉(它的工具上下文与 system prompt 都是按旧工作区装的),
  从新会话开始;有任务在跑时**直接拒绝**,不偷偷换掉正在运行的围栏。会话留档不丢,
  侧栏里不属于当前工作区的历史会话会标出 `📁 目录名`,提醒你那些文件不在当前文件夹里。
- **记忆是全局一份**(`workspaces.json`,跟 exe 走):GUI 与 CLI 读到的是同一个「上次在哪干活」;
  记录的文件夹被删/改名时静默回退默认工作区,绝不因为一个失效设置拦启动。
- 网页版(对外形态)**不开放**工作区管理:访客按 POST 调那四个方法一律被拒,前端也会把胶囊整个藏掉。

## 附件(文件 / 图片)

聊天框左侧 📎 打开系统文件选择框,可以多选:

- 文件先复制进工作区 `uploads/`(重名自动加 `-1`/`-2`),消息里注入相对路径清单,
  模型用 `read_file` / `bash` 等工具自行处理 —— PDF 这类二进制不会被硬塞进上下文;
- 图片另做压缩:长边超过 1536 等比缩小,JPEG/WebP 逐级降质量到 1MB 以内,
  带透明的 PNG 保持 PNG,GIF 保留动画;单文件上限 20MiB、解码后不超过 4000 万像素;
- `config.json` 里 `vision: true`(且模型确实支持看图)时,图片会以 base64 data URL
  随消息直接发给模型;否则只给路径并在消息里注明「当前模型不支持看图」。
- **恢复旧会话时附件以标签复原**(v0.9.69):图片带缩略图、文件显示名字与真实大小;
  附件文件后来被删了的,标签变灰并写明「已不在工作区」—— 不装作还能打开,
  也不补一张假的缩略图。

## 外接能力(OCR / 图表 / 图片生成 / 向量档)

这一节的规矩与其他能力同源:**"能用什么"由探测函数自己说,缺了只报缺什么** —— 每一句能力描述都要能追到一次真的执行分支,不许按模型名猜、不许静默换成"看起来成功了"。

| 工具 | 后端 | 缺了 / 不准的时候 |
|---|---|---|
| `ocr_image` | `system` = Windows 自带的 `Windows.Media.Ocr`(不联网、不含模型权重,用的系统语言包,但要一组可选 `winrt-*` 绑定);`vision` = 配置里的视觉模型(能不能看图只认 `model_probe` 的实测缓存结论) | 没装绑定就照实说没装 + 给可照抄的安装命令;认出来的字**只当待核对草稿**(本机实测:`f(x)`→`f 冈`、`x^2`→`x ^ 2`、减号 `−`→汉字 `一`),每条出口都带"后端 + 告警"两行 |
| `render_chart` | 只用标准库手写自包含 SVG(`bar`/`line`/`pie`,`MAX_POINTS = 200`) | 数据必须由调用方真给出来:少一个数就报错,**不把空缺插成 0**;`source` 印在脚注,没写就是空的;产物落 `工作区/charts/`,「撤销」不跟踪它 |
| `generate_image` | `api` = OpenAI 兼容 `/images/generations`(Key 借 `providers` 那份,不落 config.json);`card` = Pillow 把文字排成 PNG | 没配接口就只出文字卡片并写明「这是排版,不是 AI 绘图」,**绝不凭描述假装出图**;返回超过 12MB 拒绝落盘;产物落 `工作区/images/` |
| 知识库向量档 | `api`(`/v1/embeddings`,借已有供应商的 Key)/ `local`(ONNX 小模型 + 自带 WordPiece,**池化按模型口径选 cls/mean**) | 两档都不可用时**只跑关键词(BM25F)**,并在检索结果里写「向量档未跑:<为什么>」——把字面匹配说成语义检索就是装饰 |

开语义档的两条路:①在 `config.json` 写
`"capabilities": {"embeddings": {"backend": "api", "provider_id": "<已有供应商 id>", "model": "<embedding 模型名>"}}`;
②`{"backend": "local", "model": "<模型名>", "pooling": "cls"}` + 把 `model.onnx`、`vocab.txt` 放进
数据目录的 `models/<模型名>/`(两个文件名必须一模一样)。源码运行也可以用
`python scripts/fetch_embed_model.py --repo <组织>/<仓库>` 下(先写 `.part` 再改名;
`--sha256 文件=十六进制` 钉过才会报"已核对",没钉只报指纹)。
**模型权重不进安装包**(bge-small-zh-v1.5 那份实测 94,835,369 B),但 v0.9.123 起
`onnxruntime` + `numpy` 已经在包里,装好的便携版 / 安装版同样能跑本地档 —— 差别只剩
包里没有 `scripts/`,那一步要手工放文件。
向量索引落在数据目录 `kb-vectors/`(同样不进包),以条目正文 sha1 为键;缓存文件名带着
**会改变向量数值的那几个口径**(local 档:池化与截断宽度),换了口径就是一套新缓存,
不拿旧向量当真值。索引第一次要明确点一次头才建 —— 那是几百次向量调用,不顺手替使用者做。
查询侧的检索指令**默认不加**:2026-10-06 用那份 ONNX 在 200 条真馆藏上实测,加上
「为这个句子生成表示以用于检索相关文章：」把自召回 Top-1 从 200/200 打到 130/200,
要加就在 `capabilities.embeddings.query_prefix` 里显式写;这次跑的池化与带没带指令
都会印在检索口径那一行里。
`capabilities` 里手写的 `api_key` 会在 `save_config` 落盘前被洗掉 —— 密钥只有 credentials 那一条路。

## 长期记忆

跨会话记住四类事实:**用户偏好**(user)/**反馈纠正**(feedback)/**项目约定**(project)/
**参考资料**(reference)。分两级作用域:

| 作用域 | 存放位置 | 适用 |
|---|---|---|
| 项目级(默认) | 工作区 `memory/MEMORY.md` | 只跟这个项目有关:技术选型、目录约定、踩过的坑 |
| 用户级(`scope=user`) | `~/.yinluxs/memory/MEMORY.md` | 跨项目通用:个人偏好、沟通习惯、常用环境 |

两个文件都是**一条一行、人工可直接编辑**的 Markdown:

```markdown
- [2026-09-13][user] 喜欢先给结论再给理由
- [2026-09-13][project] 打包前必须先关掉运行中的实例
```

模型通过 `memory` 工具增删查(`save` / `list` / `search` / `forget`),系统提示词会自动
注入两级记忆(用户级在前、项目级在后,合计约 4000 字的预算)。装不下时**按条让位而不是切半句**:
两级各自从最旧的那条开始退,最新的一定在,界面上会说「本次注入最近 N 条,另有 M 条没列出」,
要翻旧账就 `list`、按词找就 `search`(`v0.9.121`;此前是按字符硬切,既会把一条记忆切成半句,
又必定整块丢掉项目级那一批)。

**整理去重(Dream `action=dream`)** —— 对齐星瑶 Y-Code 的 `/dream` 思路,分两步:

1. **确定性去重**:同类别内按中文 2-gram 相似度聚类(整体相似 ≥0.75,或短的一条被
   覆盖 ≥0.85 视为同一条),合并时保留信息最全的正文 + 较新的日期,完全重复直接丢弃;
2. **模型归纳**(有 LLM 时):让模型合并同义、删掉被后续条目推翻的,每条压成一句话,
   输出严格 JSON;解析失败或返回空就退回第 1 步的结果,绝不把记忆整理没了。

覆盖前会把原文件备份到同目录 `history/MEMORY-<时间>.md`,所以整理永远可回溯。

入口:GUI 顶栏「🧠 记忆」(点击整理两级)、CLI `/dream [project|user|all]`、
模型在用户说「整理记忆」时自行调用 `memory action=dream`。

## MCP 服务器

支持接入任意[MCP](https://modelcontextprotocol.io)服务器,外部工具会以
`mcp_<服务器>_<工具>` 的名字挂进工具集,和内置工具一样被模型调用。三种传输都支持:
**stdio**(给 `command`,子进程按行收发)、**http**(Streamable HTTP:给 `url`,POST 过去,
响应可能是 JSON 也可能是 `text/event-stream`,`Mcp-Session-Id` 会自动带上)、
**sse**(老式 HTTP+SSE:`GET` 一条长流拿到 `endpoint` 事件后再 POST 到那条地址)。
只有网址、没有启动命令的服务器从此也能连,而且**不额外依赖任何第三方库**(走标准库 `urllib`)。

**能力协商照实说(v0.9.82)**:握手时学长声明的 `capabilities` 是空的 —— 它只实现了 MCP 的 `tools` 这一个原语,`resources` / `prompts` / `sampling` / `logging` 都没接,所以不假装支持。对端在握手里声明了什么则**原样留着并说给你听**:添加服务器成功那句话会带上「对端声明: prompts、resources、tools;学长只接了 tools(prompts、resources 没实现,不会去调)」,侧栏 🔌 MCP 健康行悬停是同一句;没连上(没握过手)的服务器**不编能力表**,直说拿不到。`mcp action=list` 仍是配置层口径(它不去连服务器),活状态与能力在这两处。

**本 agent 反过来也能当服务器(v0.9.144)**:`引路学长-CLI.exe --mcp-serve`(源码态 `python main.py --mcp-serve`)在本机起一个 stdio MCP 服务端,把**校园只读能力**暴露给 Claude Code / Cursor / Qoder 一类 MCP 客户端 —— `library_search` / `library_guide` / `campus_calendar` / `gpa_calc` / `search_knowledge` / `campus_notices` / `get_weather` 与地图五件,共 12 只,**清单显式列举**(绝不用 `read_only` 标志过滤:`read_file`/`glob`/`grep` 也是只读,而工作区根就有含内置 Key 的 `config.local.json`)。两条硬边界:① 外部来的每一步都走**同一道权限门**,需要人点头的一律拒绝 —— 没有人能替这台机器的主人点头,也**没有** `--mcp-yolo` 这种例外档;② stdout 只走协议报文,人读的话全走 stderr。写盘 / 执行命令 / 读文件 / 私有数据(成绩、情绪、记忆、课表)一律不在名单里;被拒的那一次会在本机 `injection-events.log` 留一行(带客户端自述标签,`clientInfo` 只进日志、不进判定)。只做 stdio、一个进程一个客户端:不开端口、不做 http/sse、不连出站 MCP。

在 `config.json` 里配置(完整示例见 `config.example.json`):

```json
"mcp_servers": [
  {
    "id": "filesystem",
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "D:/data"],
    "enabled": true,
    "read_only": false,
    "description": "文件系统"
  },
  {
    "id": "remote-demo",
    "transport": "http",
    "url": "https://example.com/mcp",
    "headers": { "Authorization": "${MY_MCP_TOKEN}" },
    "enabled": true,
    "read_only": true,
    "description": "只有网址的服务器;密钥留在环境变量里,不写进 config.json"
  }
]
```

`headers` 里的 `${VAR}` 在**发请求时**才展开(`MY_MCP_TOKEN` 从环境变量取),配置文件中不落明文;
日志与报错里的 URL 一律**剥掉 query**,所以 token 不会顺着错误文案漏进对话。
`transport` 留空即按 `command` 走 stdio;`url` 缺失、`file:` 协议、不认识的 transport 会被跳过并说明。

| 字段 | 说明 | 默认 |
|---|---|---|
| `id` | 服务器标识,用于拼工具名(会规范化成字母数字下划线) | 必填 |
| `transport` | `stdio`(按 command 起子进程)/ `http` / `sse`;写 `streamable-http`、`http+sse` 等别名也认 | `stdio` |
| `command` / `args` | 启动命令,支持 `npx` / `uvx` / `python` 等(**stdio 时必填**) | 空 |
| `url` | 服务器地址(`http` / `sse` 时必填,只认 http/https) | 空 |
| `headers` | 附加请求头(值支持 `${VAR}` 展开,发请求时才代入) | 空 |
| `env` | 追加的环境变量(值支持 `%VAR%` / `$VAR` 展开) | 空 |
| `enabled` | 关掉可保留配置不启动 | `true` |
| `read_only` | 标记为只读 → 免确认直接执行;默认**需要用户确认** | `false` |
| `allow_tools` | 非空时**只挂列出的那几只**(精确名或末尾 `*` 前缀);留空 = 全挂 | 空 |
| `deny_tools` | 列出的那些**一律不挂**,优先级高于 `allow_tools`;写错一个字母会在侧栏/体检与添加回话里点名"没匹配到任何工具" | 空 |
| `start_timeout` / `call_timeout` | 握手 / 调用超时(秒) | 10 / 60 |
| `description` | 显示名与工具描述前缀 | 空 |

行为约定:

- **名单只收窄、不扩权**:`allow_tools`/`deny_tools` 只能让服务器声明过的工具挂不上注册表,**不能变出一只它没声明的工具**;被挡掉的只数与原因写在侧栏、体检与「已添加」那句回话里,报的只数是**真挂上来的**那只数(不是服务器自己声明的数)。
- **连不上不崩应用**:命令不存在、握手超时、协议错误都只在日志里提示并跳过该服务器;
- **进程级长连接 + 退出回收**:窗口关闭 / CLI 退出时统一终止子进程,不留孤儿;
- 工具自带 JSON Schema,权限门按 `read_only` 决定免确认还是逐个确认;
- **侧栏底部的 MCP 健康行**(v0.9.70):配置了的都在 —— 连上的显示
  `服务器名(工具数)`,没连上的写「未连上」,停用的写「停用」;
  对话里增删后当场刷新。

**预设模板库(v0.9.70,对话里说「看看有哪些 MCP 预设」)**:`mcp` 工具的
`action=list_presets` 摆出内置模板 —— `everything`(官方演示,试水用)、
`sequential-thinking`(分步思考)、`filesystem`(开放工作区之外的某个文件夹,
要给 path)、`time`(时间与时区)、`fetch`(网页转 Markdown),每条都写清
本机需要什么(`npx` 要 Node.js,`uvx` 要 uv)。加的时候 `action=add` 传
`{"preset": "<id>", "path": "D:/课件"}`(要参数的预设才需要 path)——
**命令与参数以模板为准,raw 改不动**(raw 能改 command,预设就成了任意命令
执行口子);探测闸照旧真连一次,连不上不写入,并如实说本机缺什么。

> (`gzasc` / `deepseek-v4-flash`),界面不提供切换入口。

>

> 拒绝文本里读真实上限(请求被拒=没生成 token,几乎不花钱);视觉靠发一张 1×1

> 并发布给 `model_catalog`,任务面板的能力标签、窗口上限,以及**压缩触发阈值**
> 都会自动跟上,学校换模型/换网关不必改代码。探测走后台线程,失败只是"这次没
> 测出来",不阻塞启动。

## 两个便携版(轻量版 / 完整版)

打包版联网抓取有两个引擎:轻量版不带 crawl4ai,走内置抓取器(httpx + BeautifulSoup);
完整版把 crawl4ai 与浏览器内核一起打进去,能抓需要 JS 渲染的页面。运行时自动选择,
降级时会在工具输出里说明原因。

```bash
python scripts/build_exe.py            # 轻量版:文件夹 + zip + 单文件版 + 安装包
python scripts/build_crawl4ai_exe.py   # 完整版:文件夹 + zip + 安装包(需本机有浏览器内核)
```

| | 轻量版 | 完整版 |
| --- | --- | --- |
| 产物 | `引路学长-<版本>-win64.zip`(便携)<br>`引路学长-<版本>-setup.exe`(安装包)<br>`引路学长-单文件版.exe` | `引路学长-<版本>-crawl4ai-win64.zip`(便携)<br>`引路学长-<版本>-crawl4ai-setup.exe`(安装包) |
| 抓取引擎 | 内置抓取器(无浏览器) | crawl4ai(真浏览器,可渲染 JS) |
| 解压后体积 / zip | 约 110MB / 76MB | 约 660MB / 281MB |
| 浏览器内核 | 无 | `ms-playwright/chromium_headless_shell-*`(272MB,放在 exe 同级,不塞进 exe) |
| 适用 | 日常分发、静态站点抓取 | 需要抓 JS 页面时 |

两个安装包用不同的 `AppId`,可以**同时装在一台电脑上互不覆盖**(完整版装到
`%LOCALAPPDATA%\Programs\引路学长-完整版`);便携版则是把整个文件夹拷走就能用,
配置与会话都在 exe 同目录。

完整版的浏览器内核目录可以单独拷进轻量版目录(与 exe 同级),即把轻量版升级成完整版;
反过来删掉 `ms-playwright/` 就会自动降级,不会报错。

验收(两版都可以用同一个脚本验,断言期望的引擎):

```bash
python scripts/e2e_frozen_crawl.py
python scripts/e2e_frozen_crawl.py --exe dist/引路学长-crawl4ai/引路学长-CLI.exe --expect-engine crawl4ai
```

## 打包发布

```bash
pip install -r requirements-dev.txt
python scripts/build_exe.py        # 构建 dist/引路学长/ 并生成 引路学长-<版本>-win64.zip
python scripts/e2e_frozen.py       # 对 exe 做端到端验证
```

产物三件套(dist/ 下):
- **引路学长-<版本>-setup.exe** —— Windows 安装包(推荐分享):中文向导、
  仅当前用户安装(无需管理员)、自动创建桌面/开始菜单快捷方式、带卸载器
- **引路学长-单文件版.exe** —— 免安装单文件,双击直接用(启动稍慢)
- **引路学长-0.x-win64.zip** —— 绿色便携 zip,解压即用

安装包内置全部三种 exe 形态对应的 GUI 版;`config.json` 首次启动生成在安装目录;
用户数据(config/sessions/memory)卸载时保留。

`config.json` 在 exe 旁自动生成;图标、system_prompt、前端页面、内置技能已打包。
