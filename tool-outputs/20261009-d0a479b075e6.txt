289	> ⚠️ **本节的 `N/6` 分母仍然只数最初那六家**（Codex / Claude Code / Cursor / Cline / Roo Code / Aider），**没有把新加的两家折进去**——折进去要逐条重判 12 项，且「六家都有」这类原话会全部失效，不是改个分母的事。加进 ZCode 与 Qoder 后**判定会变的两条**，先写在这里而不是偷偷改数：
290	> - **第 7 条「生命周期 Hook」**：从「4/6 强共识」升级为**八家里的 6/8 且两家都是全套**（ZCode 7 事件含 `PermissionRequest`、Qoder 27 事件含 `PreCompact`/`Elicitation`/`TeammateIdle`）。原清单里"Codex 仅 notify"这一格仍然成立。
