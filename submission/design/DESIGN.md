# 设计说明 · 暮色玻璃（Twilight Glass）

> 本项目 UI 为**代码内实现的设计系统**（单文件 HTML/CSS + 设计令牌），未使用 MasterGo/Figma 出稿。
> 在线设计稿链接（如有，请替换）：`https://mastergo.com/<待填>` / `https://figma.com/<待填>`

## 一、设计理念

全屏校园黄昏航拍照片即 UI 的一部分，所有面板用半透明磨砂玻璃浮在照片上；深浅两套主题共用同一组令牌换值。

## 二、设计令牌（节选）

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--primary` 晚霞橘 | `#F97316` | 同 | 主色、按钮、高亮 |
| `--accent` 暮色青 | `#5EB8AD` | 同 | 辅助强调 |
| `--gold` 窗灯暖金 | `#FFD9A8` | 同 | 问候语、点缀 |
| `--glass` | `rgba(252,248,241,.7)` | `rgba(11,19,27,.55)` | 侧栏/顶栏 |
| `--glass-strong` | 高可读底 | 同 | 正文气泡 |
| `--r-full / --r-m / --r-s` | 胶囊/中/小圆角 | 同 | 同心圆角体系 |
| `--blur` | `saturate(150%) blur(18px)` | 同 | 背景模糊 |

## 三、关键界面

- **首页**：按系统时间问候（凌晨/清晨/…/晚上好，同学！）+「🗺 打开校园地图」「📚 图书馆导览」固定入口 + 9 个动态建议 chips。
- **聊天**：用户实心橘气泡、助手近乎不透明气泡；思考与工具调用收成可折叠「工作过程」；划词浮动复制条。
- **校园地图面板**：手绘底图 + 搜索 + 类别图例筛选 + 详情卡（邻近跳转/复制位置）+ 单栋标注图灯箱。
- **权限确认框**：顶部「为什么要做这一步 / 会做什么 / 影响」三行说明。
