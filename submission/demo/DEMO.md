# 演示与部署 · 引路学长 v0.9.0

## 一、部署地址

本软件是**本地桌面应用**（GUI + CLI），无常驻服务器，故无公网 URL。三种「地址」：

| 形态 | 获取/运行方式 |
| --- | --- |
| 安装包 | `dist/引路学长-0.9.0-crawl4ai-setup.exe` → 双击安装，开始菜单启动 |
| 便携版 | 解压 `dist/引路学长-0.9.0-crawl4ai-win64.zip` → 双击 `引路学长.exe` |
| 源码 | `python gui_main.py`（桌面）/ `python main.py "问题"`（CLI） |

> 若需公网演示地址：把便携版部署到一台带 WebView 的机器并录屏，或用「网页版（校园助手）」本地起服务后内网访问（见主 README「网页版」）。

## 二、演示脚本（建议 3–4 分钟）

1. 装机/解压 → 首启自动生成 `config.json`，顶栏显示内置校园模型。
2. 点首页「📚 图书馆导览」→ 自动发起「带我走一遍从查书到借书」，展示楼层/空间/流程。
3. 问「图书馆有没有《三体》?在几楼?」→ 毫秒返回索书号 I247.5/868 + 二楼/三楼 201 文学新书区。
4. 问「开放时间是几点?」→ 如实说明无官方口径、给官方入口，**不编数字**（亮点：可信）。
5. 点「🗺 校园地图」→ 搜「E栋」出候选、搜「旧图」定位图书馆、点类别图例筛选宿舍。
6. 问一个校园政策（如「国家奖学金怎么申请」）→ 检索本地知识库并附来源网址。
7. 编程引路：让它读一个文件/跑一条命令，展示沙箱确认框「为什么要做这一步」。
