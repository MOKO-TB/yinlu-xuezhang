# 二维码

把**安装包网盘链接**或**部署地址**做成二维码，答辩现场扫码即可下载体验。

## 生成

```bash
pip install qrcode pillow
py -3.12 generate_qr.py "https://你的真实下载链接" 下载二维码.png
```

生成后把 `下载二维码.png` 放本目录，并贴到 PPT 尾页。
