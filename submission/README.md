# 引路学长 · 校园 AI 助手 / 编程引路智能体

> 面向**广州应用科技学院**在校生的桌面端 AI 助手：既能回答校园问题（图书馆、找楼、奖助、竞赛、考研…），也是一个可读写文件、跑命令、联网抓取的**编程引路智能体**。GUI 与 CLI 同一内核，本地运行、离线数据秒回。

---

## 一、项目介绍

| 项 | 说明 |
| --- | --- |
| 一句话定位 | 把「校园信息」和「编程带教」合进一个本地桌面智能体，新生装机即用、不等网络 |
| 对标 | 自研编码智能体（Agent 主循环 + 工具调用 + 权限门 + 沙箱），叠加校园化门面与数据 |

| 内置工具 | **18** 个只读/可写工具 + 子代理 `task` + MCP 动态外部工具 |
| 数据资产 | 校园知识库 **757** 条 · 图书馆馆藏 **1,331,774** 条 · 校园地图 **36** 建筑 / **203** 别名 · 技能 **8** 个 |

| 运行方式 | 本地桌面应用，无服务器依赖；模型走内置校园端点，用户不填密钥 |

## 三、用户痛点

| # | 痛点 | 现状 | 我们的解法 |
| --- | --- | --- | --- |
| 1 | 新生找不到楼、分不清校区地点 | 官网无导航，问人靠嘴 | 校园地图：36 建筑 + 203 别名，「E栋/s5/旧图」口语也能定位；**歧义不猜**（A–E 栋必追问） |
| 2 | 校园信息散在官网/公众号，检索难、时效不清 | 翻通知、问辅导员 | 本地知识库 757 条，**带来源网址 + 可信度分级**；未命中定向爬官网补库 |
| 3 | 图书馆藏书/楼层/借还流程不熟，官网查得慢 | OPAC 是 JS 门户，翻页等网络 | **133 万条离线馆藏**毫秒查 + 索书号→楼层映射 + 导览模块（空间/流程） |
| 4 | 编程入门没人带、卡住就放弃 | 问群、搜帖子 | 编程引路智能体：读写文件、跑命令、看报错、给步骤，配技能与长期记忆 |

## 四、核心功能

- **Agent 内核**：主循环 + 18 内置工具（文件/命令/检索/抓取/计划/记忆/地图/图书馆）+ 子代理 + MCP 外部工具。
- **权限门 + 沙箱**：敏感路径永久硬拒、工作区外逐次确认、`accept_all` 也越不过；命令超时钳制。
- **校园知识库**：`search_knowledge` 2-gram 打分，输出来源与可信度；`web_crawl` 定向补库（打包版用内置轻量抓取器，完整版带 crawl4ai）。
- **图书馆模块**：`library_search`（133 万条，毫秒级，结果自带「中图法→楼层」）+ `library_guide`（楼层/空间/借还流程/官方入口），规则类无官方来源则如实标注、不编造。
- **校园地图**：`map_find_place / show_list / highlight_building / drop_pin / clear`，手绘底图 + 索引坐标，纯前端交互不耗模型调用。
- **长期记忆**：项目级 + 用户级全局，去重归并 + Dream 整理（模型归纳、覆盖前自动备份）。
- **技能系统**：`SKILL.md` 8 个（图书馆导览、校园问答、自行车停放、话术规范、口碑提取、代码审查、Git 提交、Python 测试）。
- **GUI 体验**：暮色玻璃全屏校园背景、深浅主题、按时间问候、动态建议 chips、后台多会话并发、工作过程折叠、划词复制、编辑重发。
- **三形态分发**：安装包 / 单文件免解压 / 便携 zip；完整版内置 crawl4ai + 无头浏览器内核 + 1.3GB 馆藏库，装机即可用。

## 六、快速开始

```bash
# 源码运行
pip install -r requirements.txt
python gui_main.py        # 桌面版
python main.py "帮我查一下图书馆有没有《三体》"   # CLI 单次任务

# 发行包：解压 引路学长-crawl4ai/ 双击 引路学长.exe，或运行 setup 安装
```
