## 现状(2026-09-26 逐行读过,不是回忆)

已有的**心跳**其实齐了,缺的不是线程:

| 已有 | 在哪 | 干什么 |
| --- | --- | --- |
| 主循环线程 | `proactive.start_loop` | 约 6 小时一轮(简报、校历倒计时那类) |
| 细轮询线程 | `proactive.start_tick_loop`(≈685 行起) | 每 `CLASS_TICK_SECONDS`(300 s)看一次"20 分钟内开课/到期" |
| 按天去重账本 | `pushed-today.json` + `was_pushed`/`mark_pushed`(`PUSHED_CAP = 200`) | 同一件事一天内只催一次;按天滚动,重启不丢 |
| 现场日志 | `wd_log` → `watchdog.log` | 只记类别 + 去重键 + 结论,绝不记正文 |
| 开机补发 | `catch_up` | 补三件:今日简报 / 错过的课(60 min 窗口)/ 刚过期的待办 |
| 生产者 | `schedule.late_class_note`、`reminders.late_due`、`push_briefing` | **各自硬编码一段判断 + 自造一个去重键** |

**真正的缺口**:没有任何地方记着"这件事多久跑一次、上次什么时候跑的、下次该在什么时候"。
所以每加一种周期 —— 周复盘(每周一)、缺口周报(每周日)、考试闭环(按校历倒计时)—— 都要在
`proactive.py` 里新写一段 if 判断并再造一个键,加到第四种时那段循环自己就成了热点。

### A2 · 接线(最小一刀:只让新任务走表,不动现有三类)

`_tick` 与主循环各加一行"过一遍到期任务"。**课前提醒与待办到点保持原路** —— 它们的语义是
"提前量 + 补发窗口",不是 cadence;硬塞进 A0 的模型会把 `test_proactive*` 那批既有针全推翻,
收益却是零。这一包是唯一碰运行路径的地方,单独一轮做。

### A3 · 循环待办

`reminders` 里支持 `repeat`(每周 / 每 N 天)。校历那套 `repeat: "yearly"`(v0.9.32)已有先例,
照它的路子走:投影出来的下一次带 `projected` 与锚点日期,**7 天倒计时一律不采用投影日期**
(我们推的日子不配拿去催人),这条老规矩要一起继承。

### A4 · 周报两件(周复盘 / 缺口周报)

- **周复盘**:回读 `mood` 已有的每周回顾内容,到点说一句 + 给一条可复制的追问。
- **缺口周报**:聚合 `kb-gaps.jsonl`(v0.9.39 起 `growth.log_kb_gap` 就在落这份文件)最近一段的
  top N 问法,报"库里接不住的是哪些问法"。
- 两件都**只说不做**:不自动调模型、不自动爬 —— 那会花同学的 Key 额度,必须是显式动作。

### A5 · .ics 兜底 + 考试闭环

校历与待办导出 `.ics`(§6 第 18 条里 2026-09-22 那轮用户没点的"② 导出 .ics"),`skills/ics-calendar`
已有技能教模型怎么写这个文件,所以 A5 缺的只是"到点主动提一句"。考试闭环 = 校历考试周
+ 倒计时任务 + 一句"要不要排复习计划"。

## 划掉的做法(以及为什么不成立)

- **不引 APScheduler / croniter**:这仓库一路守"零新依赖"(打包体积与 PyInstaller 隐藏导入都是真代价),
  而 cadence 只有五种形态,手写三十行 + 全覆盖测试比引一个调度器便宜得多。
- **不挂 Windows 任务计划程序**:托盘常驻本来就在跑两套循环,再加一个系统级调度器等于
  两个调度器互不知道对方跑过没有,`pushed-today.json` 那本账必然分家。
- **不把课前/待办迁进任务表**:见 A2。
- **不做"定时跑任意模型任务"**:理由同 A4 的"只说不做"。

## 三处待拍板

1. **A1 账本另开一个文件,还是并入现有 JSON?** 推荐**另开** `jobs-state.json`:
   `pushed-today.json` 与 `notice-watch.json` 记的是"今天推过哪几条",语义是事件流水;
   任务表记的是"每个任务上次何时跑",合并会让两边的去重逻辑互相纠缠。
2. **本轮做到 A 几?** 推荐 **A0 + A1**:两包都是纯函数 + 一个账本文件,可完整单测、
   不碰任何运行路径,出包风险为零;A2 接线单独一轮,好回滚。
3. **周报要不要在界面上有落点?** 推荐**先不要**:聊天里一句话 + 一条可复制的追问就够,
   开面板等于新增一块要维护的视图(与 §4 那条"新界面须进《使用说明》"的税一起付)。
