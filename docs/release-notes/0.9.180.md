# 引路学长 v0.9.180

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 这一版把"第一次升级"也变成小包

v0.9.178 开始，更新时会比一眼本机那两块大资料（内置馆藏图书馆 1.31 GB、浏览器内核 731 MB）的身份：对得上就跳过它们，只下 135 MB 的那一件。

但当时有一句实话摆在那里：**从 0.9.177 及更早的版本升上来的第一次，仍然要下 878 MB 的完整包** —— 因为老版本的安装目录里根本没有"浏览器内核身份"那份凭证，学长没法证明你机器上的内核和这一版要的是同一个。

这一版把那句实话改掉了：**本机自己核对一次。**

- 更新检查发现"内核装在本机、凭证却没有"时，就地把那 603 个文件算一遍再与发布清单比；
- 实测这台机器：**697 MB / 603 个文件 = 1.0 秒**（机械盘的老机器会是十几秒级，而且**只在"否则就要下 878 MB"的时候才付这一次**）；
- 对得上 → 和所有机器一样走 **135 MB** 那件，并把这份凭证留在本机，以后只读几十个字节的 JSON；
- 对不上、或者算不动（目录被删过）→ 照旧下整包，卡上把原因说出来。

所以：**现在从 0.9.176 / 0.9.177 / 0.9.178 点「更新」，第一次就是 135 MB，不再是 878 MB。**

顺手修的另一半（同一批机器上的）：那份凭证是随安装包写在 **exe 旁边**的，而代码之前只去"用户数据目录"里找它。装进 `Program Files` 的机器上这两处不是同一个地方（数据会被搬到 `%LOCALAPPDATA%`），于是那批机器**永远读不到凭证、每次都白下整包**。现在两处都认。

## 两件没变、也没被夸大的事

- **135 MB 不等于"只下载变化的内容"**。一轮真实变化其实只有约 1.7 MB 代码 + 0.67 MB 前端，剩下的 133 MB 是它们所在的那个容器（Python 运行时与依赖，改一行整块都要重下）。要下 MB 级得把学长自己的代码从容器里拆出来，那是另一件事，这一版没做。
- **哪两块数据真的变了的那一版，仍然下整包**（比如重新出馆藏库的那一版）。"单独下载并原地替换那两件数据"也还没做。

以及老规矩：**仍然要你点两次**（下载一次、运行安装程序一次，不会静默安装、不会自己重启），**仍然核对过才让装**（下载回来与发布清单逐字节比 sha256，对不上就删掉、按钮是灰的）。
