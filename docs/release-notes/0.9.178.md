# 引路学长 v0.9.178

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 本次更新(v0.9.177 → v0.9.178)

### ⬇️ 升级不用再重下整个产品了：878 MB → 135 MB

有同学反馈：**「改一行为什么要下 878 MB？感觉是把最新版本重新下一遍，而不是更新新的内容。」**

这个直觉是对的，而且比他以为的更严重。我们先去量，没有猜：

- 那 878 MB 里，**84.6% 是内置的馆藏图书馆数据库（59.7%）和浏览器内核（24.9%）** —— 这两块跨版本基本不变；
- 而学长自己的代码，在装好的包里只有 **约 1.7 MB**。

也就是说：为了那点真正的改动，你每次都要重搬一遍 1.3 GB 的图书馆和 700 MB 的内核。

现在不会了。发布时除了完整安装包，**多产一件「仅 app」安装包**，并随发布带一份**清单**（记录各件的大小与校验值，以及那两块数据的"身份"）。更新时学长先比一眼本机那两块数据的凭证与这一版要的是否一致：

- **一致** → 跳过它们，只下 **135 MB** 那一件（卡上那句实测长这样：「⚡ 馆藏库与浏览器内核你机器上已有，这次跳过它们能少下 743 MB（整包 878 MB） · 这次要下 135 MB」）；
- **不一致**（比如这一版更新了馆藏库）→ 照旧下整包，因为那件小包里没有新库；
- **比不了**（机器上没有那份凭证）→ 也照旧下整包。

⚠ **有一条要说在前面，别让你以为它没生效**：**从 v0.9.177 及更早的版本升上来的这第一次，仍然会下整包 878 MB** —— 因为老版本的安装目录里没有"浏览器内核凭证"这份文件，学长**没法证明**你机器上的内核和这一版要的是同一个，就只能按"不一致"处理。**装上 v0.9.178 之后，从下一次升级开始才是 135 MB。**

这不是偷懒，是这一格唯一诚实的做法：**"证明不了一致"不能当成"一致"**。猜一次身份的代价是可能给你装出一个内核不匹配、抓取功能悄悄坏掉的包 —— 那比多下 700 MB 难查得多。界面上这两种情况说的话也不一样：一种写"这一件里带着新内核"，一种写"本机没有凭证"，不会糊成一句"更新失败"。

### 其它没变的两件事

- **仍然要你点两次**：下载一次、运行安装程序一次。不会静默安装，也不会趁你不在时自己升级。
- **仍然核对过才让装**：下载回来与发布清单里的 sha256 逐字节比对，对不上就当场删掉、按钮是灰的。

一句边界（增量没有改变它）：那份凭证文件只决定**"下哪一件"**，不决定**"能不能装"** —— 它在本机是可写的，伪造一份最多让这台机器去下一件更小的包，下载回来照样要过 sha256。而校验清单和安装包来自**同一个**发布页，所以它防的是"下载坏了 / 被截断 / 链接被换到别处"，**不防发布账号本身被接管**；真要防那一层需要代码签名，这个项目没有代码签名证书。这条写在 `SECURITY.md` 新增的那一节里。
