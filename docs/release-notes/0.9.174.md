# 引路学长 v0.9.174

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 本次更新(v0.9.173 → v0.9.174)

### 🎨 浅色主题下「看不见的文字」修好了
- 「快捷键速查中心」(顶栏那一颗,或 `Ctrl+/`)的说明文字与键帽在浅色下几乎看不见。**根因不是配色不好看**:那批颜色名字在代码里**从来就没定义过**(`--text-soft` / `--kbd-bg` / `--text-bright` / `--border-soft` / `--shadow-lg` / `--glass-soft` / `--text` / `--ok` / `--warn` 九个),程序退回的是照着深色写的白色(`rgba(255,255,255,.7)`、`#fff`),放在浅色底上等于没有 —— 其中 `--glass-soft` 连回退值都没写,那几条背景声明是被浏览器**整条丢掉**的。
- 现在两种主题各有一套自己的值,调用点一个字都没改;顺手把整个前端扫了一遍,除了运行时由脚本设置的那两个,再无"未定义的颜色名字"。

### 🔄 「检查更新」现在找得到了
- 以前只有一条路:**点侧栏那个小版本号** —— 而它长得不像按钮。现在它旁边多一枚 **↻**(点哪个都行),**`Ctrl+Shift+P` 的命令面板里也有一条「检查更新」**;启动时的提示条照旧(只有真有新版本才出现)。
- 三条路同一个后端,一份真相。`config.json` 里把 `update_check` 置 `false` 关掉之后,连手动那条也一起拒(完全不出网)。

### 🔐 顺手挖出一个「会让人以为这功能是坏的」的 bug(证书被接管)
- 有些机器上 HTTPS 被**加速器 / 公司代理 / 安全软件接管**(它把自己那张根证书装进
  **Windows 证书库**,却不装进 Python 包里那份 CA 名单)。表现是:浏览器上得去、Windows
  处处上得去,而程序一调 GitHub 就是 `CERTIFICATE_VERIFY_FAILED`。
- 后果是**「检查更新」永远静默**:自动那条一次都没问出去(它本来就以静默为对),而手动
  那条回你一句「已是最新版本」—— **那句是假的**。
- 现在:证书这一关会**换系统证书库再试一次**,两次都失败才算真的不通,并且把那句实话
  弹给你(不再把"问不出去"说成"已是最新")。开发机实测就是这一种,修完手动查真问到了。

### 🗑 语音输入撤下(按用户要求)
- 输入框左边那颗 🎤 不在了;离线识别模块、桥上的两个接口、相关文档条目与那 8 支测试一并删除。历史记录保留并标了「已撤下」,不再作为可用能力。

### 上一个版本(v0.9.173)的主干,一并进包
- **看图**:模型现在能「看见」工作区里的图片(自己画的图表、生成的图、网页截图),不再只能凭代码猜 —— 只认工作区内的图,敏感目录/凭据文件/工作区外一律不看,不支持视觉的模型会明说「没有把图发出去」。
- **递话**:正在跑的子代理与别的活会话之间能留一句话。递过去的句子落在对方**下一次请求的系统侧注记**里,**绝不冒充用户说的话**;对方跑完就摘盒,递给不在的对象会得到一句实话。
- **工具钩子**:事件从 7 类补到 9 类(新增「工具失败」与「子代理起跑 / 收口」),失败语义可配(`failure_mode`,与老名字 `on_error` 是同一件事,支持全局默认)。
- **工具面按需加载**:配置里写 `tool_loading: "lazy"` 可以把每轮固定开销省掉约四分之一(二十来只校园/地图/馆藏类工具收成系统提示词里的一行索引,模型要用时自己取回来)。**默认仍是 `all`** = 与之前逐字一样。
