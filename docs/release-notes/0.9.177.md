# 引路学长 v0.9.177

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 本次更新(v0.9.176 → v0.9.177)

### ⬇️ 上一版「下载更新」在某些网络里点了没反应 —— 修好了

先说清楚:**这不是网络的问题,是两处自家代码的问题**,而且两处都是"失败得很诚实、功能却不成立"那一类。

- **第一处**:查版本、列历史、取校验文件那三条路,在证书被加速器/公司代理接管的机器上会**换一次系统证书库再试**;而**下载安装包那一条从来没走这份底座**(它自己造的客户端只认包内那份 CA 名单)。表现就是你看到的:卡开得出、按钮点得动,进度条一动不动。现在四条路真的共用同一份。
- **第二处**:把取校验清单改到新的那一跳之后,那个接口发的是 **302 跳转**,而取清单的那只手**不跟跳转** —— 于是清单永远取回空的,`核对通过`永远达不成,**「运行安装程序」那颗按钮就永远是灰的**(下载本身反而是好的)。这条是出包前拿真实的 GitHub 发布物跑了一遍才撞出来的,不是测试跑出来的。
- 下载现在**优先走另一个域名**,`github.com` 走不通时照样能下(校园网里前者慢或不通是常态);那条老地址留在后面兜底。
- 修完的实测数字:取校验清单 **0.89 秒**拿到内容,与本机对同一件安装包实算的 SHA256 **逐字相等**;那件 920 MB 的安装包按偏移取头 1 MB,206 + 真字节,**2.3 秒**。

### ⏸ 下一半不用重来

取消、断网、字节没下完 —— 这三种情况现在都**留着那半截**,下次点「下载更新」从原位接着往下走,进度条不从 0 开始,卡上会写清"这几十 MB 是本机原有的"。

- 只有两种情况会重来:服务器不认这次续传的请求(那就从 0 下,**绝不把两份不同来源的字节接在一起**),以及**校验对不上**(那种必须删掉,留着它下次还是坏的)。
- 重启过也一样:界面一开就会问一句"有没有下了一半的东西",有就照实说,不装作没发生。

### 🧹 旧安装包能清了,而且「我的数据」里看得见这笔占用

升级一次留一件 920 MB 的包,升三次就是 2.7 GB —— 而这一格以前**只会往里写、从不删**,「我的数据」面板里连它的影子都没有。

- 「历史更新内容」那一屏多一颗「**清理旧安装包**」,点一下告诉你清掉几件、腾出多少;
- 只清**这条更新通道自己下载的那几个文件**(按文件名形状认),这个目录里你放别的东西一个都不碰;
- 正在用的这一版、和眼下最新要装的那一版都会留着 —— 留着拷给另一台机器是真会发生的用途,所以**这一下由你点,不自动跑**。

### 🖱 版本号那串字可以点了 = 看历史更新内容

按你的要求,**版本号右边那枚 ↻ 撤掉了**。现在点侧栏那串 `v0.9.177` 直接开「历史更新内容」(一版一行,点开看每一版改了什么,"正在用"标在哪一版也写着)。手动「检查更新」没删,挪到命令面板里(`Ctrl+Shift+P` 搜"检查更新")。

查到新版本时那张「发现新版本」的卡照旧**自己弹出来**,点它就是下载/更新这条路。

### ⌨ 终端里学长正跑着的时候,可以直接插一句话

以前只有桌面版能这样。现在命令行里,学长干活时你打的字**回车就传进这一条会话**,它会在下一步接上(和桌面版同一个入口、同一份留档)。

- 只吃"正在跑着的时候"按下的键:回合结束就收手,所以**历史、补全、行编辑一个都不掉**;
- 管道和重定向里的输入一个字都不动(`echo /exit | python main.exe` 这类照旧);
- `Ctrl+C` 还是原来那件事(中断这一步),它不会被插话吃掉;
- 信箱满了会**当场告诉你没接**,不会让你以为说过了。

### 🧩 学长写下的网页和图,现在在对话里就地显形

它写 `.html` / `.svg`(图表、复盘页、给同学看的对比表)时,那一步下面会多一张「**可交互产物**」的卡,点开就在对话里显示,不用去文件管理器里找。

**这一格要紧的话是:显示的是内容,不是代码。** 两处各管一半,不是靠一个开关:

- 交给你看之前,**可执行的结构先删掉** —— 脚本、事件属性、可执行链接、能引外部代码的标签,删了几处**如实写在卡上**("拆掉了:脚本 1 处"),不会悄悄改内容却不吭声;
- 显示时再锁进一个**碰不到宿主、也不能提交表单、也不能跳走**的窗口,并配一条**断外联**的规则。

这个"两处都要"是实测出来的:第一版只有那个窗口,结果产物里一张**普通的图片**照样把请求发出去了 —— 窗口管执行、不管外联。补上之后同一个探针从收到 1 次变成 0 次。

- 只在工作区里取文件,路径带 `..`、带盘符、指向别的机器的都会被拒(并说清是哪一种);
- 超过 512 KB 就**拒绝显示而不是截一半** —— 一张显示了一半的表看起来像一张完整的表,那比显示不出来更坏;
- 卡上不写本机绝对路径(这东西是要被截图分享的)。

## 一句要说准的边界

校验清单和安装包来自**同一个**发布页,所以它防的是"下载坏了 / 被截断 / 链接被换到别处",**不防 GitHub 账号本身被接管**。真要防那一层需要代码签名,而这个项目没有代码签名证书 —— 这条写在 `SECURITY.md`(这一版新增了两节:「就地显示一份网页产物」和原来那节「就地更新的信任边界」),不包装成"已校验,绝对安全"。

下载与安装仍然**要你点两次**(下载 → 运行安装程序)。没有静默安装,也不会趁你不在的时候自己升级。
