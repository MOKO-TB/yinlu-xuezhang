# 引路学长 v0.9.179

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 这一版只修一件事（重要）

**修掉「升级时说下整包、实际递给你的是小包」这条缺陷。**

上一版 v0.9.178 开始，更新时会先比一眼你机器上那两块大资料（内置馆藏图书馆、浏览器内核）的凭证：对得上就只下 135 MB 的那一件，对不上就下 878 MB 的完整包。

问题出在"对不上"那一条路上：程序挑文件时用的是"名字以 `setup.exe` 结尾"这个判断，而那个 135 MB 的**仅 app 包**名字是 `…-app-setup.exe`，**它也以 `setup.exe` 结尾**；发布页又是按字母序排的，它正好排在完整包前面。结果就是：

- **从 v0.9.177 及更早升上来的机器，全部会走这条路**（老机器的安装目录里没有内核凭证，一定判"对不上"）；
- 判成"下整包"，拿回来的却是 135 MB 那件 —— **装完没有 1.31 GB 的馆藏图书馆，也没有浏览器内核**，搜书与网页抓取会不可用，而界面上写的是"按整包下"。

现在改成：**发布清单在场时，两件的名字都从清单里逐字取**，不再靠后缀猜；后缀那条路只留给没有清单的旧版发布，并且明确排除"仅 app"包。

⚠ **如果你已经升到 v0.9.178，并且发现「馆藏图书馆搜不到书」或「网页抓取报没有浏览器」**：那就是拿到了那件小包。请**用本页的 `yinlu-xuezhang-0.9.179-setup.exe`（完整包）重装一次**，你自己的数据（`config.json`、`sessions/`、`memory/`、成绩/课表/心情）都在原地不动，重装不会丢。

## 怎么判断自己有没有踩到

看侧栏版本号 → 历史更新内容那屏，或直接问一句「我的馆藏库在不在」。完整包里那两块资料分别是 1.31 GB 的 `crawled/…/library.db` 和 731 MB 的 `ms-playwright/`；也可以在本机的安装目录里看这两个东西在不在。

## 其余没变的两件事

- **仍然要你点两次**：下载一次、运行安装程序一次。不会静默安装，也不会趁你不在时自己升级。
- **仍然核对过才让装**：下载回来与发布清单里的 sha256 逐字节比对，对不上就当场删掉、按钮是灰的。
