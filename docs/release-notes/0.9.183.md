# 引路学长 v0.9.183

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 这一版做的事：更新开始只换"变掉的那几件"

以前更新的最小单位是「一整件安装包」—— 哪怕只改了一个文件,也要把 135 MB 重新拉一遍。

现在发布时会同时产出两样新东西：

- **文件级清单**：安装树里每个随包文件的路径、大小、sha256；
- **按来源版本的补丁包**：只装"与那一版哈希对不上的那些文件"。

你的机器如果正好有对应补丁,下载量就从 135 MB 降到这次真正变了的那点字节。

### ⚠ 一句必须说在前面的实话

**装上这一版本身仍然要走一次完整下载。** 上一版（0.9.181）的发布里没有文件级清单,所以没有"从 0.9.181 出发"的补丁可下 —— 增量是从**「0.9.183 → 下一版」**开始的。这一版你拿到的是能力,不是这一次的节省。

## 它是怎么工作的（以及为什么不在程序里换自己的文件）

1. **先问一句有没有对应补丁**：有就只下那一件,下完**逐件**按清单验 sha256,验不过整份暂存删掉重来。
2. **应用由一个独立脚本在你退出之后做**：程序正在跑的时候,它自己的 exe 和它加载的那些 dll 是被系统锁着的 —— 边跑边换的结果是"半新半旧",那比不更新更坏。所以点"应用"时,程序把自己的进程号交给脚本,脚本**等这份进程消失**才开始搬文件。
3. **原件先进回滚目录**：任何一件对不上,就把已经搬走的**整体搬回去**,并把结局写进状态文件。更新失败可以是"没更新",不能是半新半旧;回滚之后旧版本照样能启动。
4. **没有对应补丁就照旧下整件**：跳了好几版、或那一版没出清单,都走这条 —— 这条路不覆盖那一台不是失败。

## 三件没变的事（说了你以为做了）

- **仍然点两次**：下载一次、应用一次。不会静默安装、不会自己重启、也不会替你关窗口。
- **该核对的 sha256 一个字都不少**：清单与安装包同源(同一份发布资产),不引入第三方镜像信任;清单里出现绝对路径、`..`、或指向馆藏库/内核/你的会话数据的条目,**整份拒收**。
- **你的数据不在更新范围内**：馆藏库与浏览器内核归"数据身份"那套管(对得上就跳过),会话、配置、密钥、检查点永远不会被这次更新碰。

## 顺带修掉的两个 PowerShell 坑（记在这里是为了别把它当玄学）

- `Move-Item` 的源和目标都写成 `-LiteralPath` → PowerShell 报"参数被指定了多次",整次回滚;
- PowerShell 5.1 的 `Set-Content -Encoding utf8` **带 BOM**,状态文件读出来是空 —— 现在用 .NET 写无 BOM,读的时候也容 BOM。
