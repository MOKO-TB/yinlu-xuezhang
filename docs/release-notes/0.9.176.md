# 引路学长 v0.9.176

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 本次更新(v0.9.175 → v0.9.176)

### 🔔 有更新会自己来说了
以前查到新版本,只在聊天栏顶部留一条提示 —— 而那条会被别的推送挤掉,也容易被当成界面装饰;更多时候是用户自己想起来去点版本号旁边那枚 ↻。现在:

- 侧栏版本号旁边多一枚**绿色「更新」徽章**,只要有新版本它就在;
- 并且**自己弹一张「发现新版本」的卡**:版本号、发布日期、整段更新日志;
- 卡上可以点「**查看历史更新内容**」,一版一行、点开看每一版改了什么;
- 不想被打扰:`config.json` 里 `update_check:false` 整条通道关掉(连手动那颗也一起拒,关掉就是真的不出网);只想安静这一版,点「**跳过此版本**」—— 它跳的是那一版,下次发更新的版本照样会告诉你。

### ⬇️ 下载更新就地装好,不用把你丢去网页
卡上那颗「下载更新」直接把该下的那一件下到本机:`setup.exe`(装机 / 目录版)或单文件版本体 —— 按你现在跑的是哪一版自动挑。

- 有**进度条**(百分比 + 已下多少 MB),可以中途取消;关一下窗口再回来,进度还在;
- 下完会跟发布时那份 **sha256 核对**:对不上就**当场把文件删掉**,界面上那颗「运行安装程序」是灰的;拿不到校验文件时会明说"没做校验",同样不给装 —— 把"没验过"说成"验过了"是这种事上最坏的一种;
- **要点两次**:下载一次、运行一次。没有静默安装,也不会趁你不在的时候自己升级 —— 那等于让一次网络回答获得改这台机器的权力;
- 取消、中断、字节数对不上,这三种情况都不会在你机器上留一个半截的 `.part` 文件。

一句要说准的边界:那份校验清单和安装包来自**同一个**发布页,所以它防的是"下载坏了 / 被截断 / 链接被换到别处",**不防 GitHub 账号本身被接管**。真要防那一层需要代码签名,而这个项目没有代码签名证书 —— 这条写在 `SECURITY.md` 的「就地更新的信任边界」里,不包装成"已校验,绝对安全"。

### 🐛 顺手修掉一处会让"我已经关掉了"变成空话的 bug
`update_check`(关掉更新检查)、`subagent_nesting`(子代理嵌套)、`shadow_git`(影子仓库)这三枚开关,程序读它们,但**写配置时不在那份名单里** —— 表现是:你在 `config.json` 里写了 `update_check:false`,之后只要在「模型管理」里勾一下、或者装一次工具钩子,它就被悄悄写回 `true`。那句"关掉就完全不出网"的承诺于是是空的。

现在三枚都进了写回的名单,并且立了一道对账闸:**配置读的键必须都在写回的键里**,再加开关时漏了会当场红。

### 上一个版本(v0.9.175)的主干,一并进包
- **启动那一下不再卡好几秒**:系统提示词里那句馆藏统计原先让数据库把 1.31 GB 的馆藏库整个扫一遍,而库里那两个索引本来就在;拆成各走索引后本机实测约 1.5 秒 → 0.2 秒,报的四个数一个没变,也没多存一份缓存文件。
- **MCP 服务器的「提示模板」现在能用了**:列清单、按名字取内容;那是那台服务器写的指示,所以每次取都会问你一句。
