# 引路学长 v0.9.184

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 这一版修两处用户直接撞上的显示问题

### 1. 导入课表/成绩后点开是空的

课程表那张弹窗和右边的侧栏**用了同一个内部名字**(`id="scBody"`)。浏览器只认第一个,于是课表和成绩统计被写进了侧栏那一格,弹窗自己只剩一个空壳 —— **数据没丢,是显示接错了地方**。

改名之后两处各回各家。更关键的是加了一道**常闸**：整份界面里同一个名字不许用两次,以后再撞这种"两个组件抢一个容器"会当场红,而不是等同学发一张截图过来。

### 2. 「历史更新内容」点开只剩一句 HTTP 403

这一屏原来是**每点一次就打一次** GitHub 的公开接口。那个接口对没登录的机器按 IP 限流，**每小时只有 60 次**；而后台除了这一屏，还每几小时自己查一次新版本（每次启动后 15 秒也要查一遍）。配额是被这台机器自己用完的 —— 用完之后那一屏就只能回一句「接口回了 HTTP 403」。

现在：

- 取到的历史列表**存在本机**（`release-notes.json`，在「我的数据」里能看到那一格，删了下一次自己重新取）；
- 这一屏**一天最多出网一次**，其余时候直接读盘上那份，屏上会写明「本机缓存 · 上次取到 2026-10-18 09:12:34」——**不会把缓存说成实时读数**；
- 后台查版本改成**一天一次**（启动后那一遍就是当天那一遍），查到新版本照常弹卡推给你；
- 每天那一次出网会顺手把整份历史列表也取回来，所以你哪天点开都不用现场等网络，**断网那天也翻得着旧版本写了什么**；
- 问不到（断网 / 配额 / 接口形状变了）不把今天划掉，但一小时内不再撞第二次。

### 一句要提前说的取舍

改成一天一次之后，**如果新版本是在你当天那次检查之后才发布的，要等第二天的那一遍才会弹给你**。这是"省配额"与"第一时间知道"之间拍的板，选的是前者。随时想知道的话：命令面板（Ctrl+Shift+P）里的「检查更新」不受此限，那是你自己按的，它当场就问。

## 没有变的

- 仍然要点两次才装：下载一次、运行一次；不静默安装、不自己重启、不替你关窗口。
- 仍然只读 GitHub 的**公开** Release 接口，不上传任何东西，不建云账号，不做遥测。缓存里只有公开发布的版本号和说明文字，没有你的数据。
- 关掉的语义仍然关死：`update_check: false` 时这一屏和后台检查都不出网（连手动那颗也拒）。
