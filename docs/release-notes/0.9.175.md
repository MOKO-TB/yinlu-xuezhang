# 引路学长 v0.9.175

校园 AI 助手 / 编程引路智能体 —— 终端与桌面窗口双形态,内置校园模型,开箱即用。**完全本地运行**,不填 API Key 也能用。

## 本次更新(v0.9.174 → v0.9.175)

这一版是两件"把已经存在的东西接上"的活,没有新界面。

### ⚡ 启动那一下不再卡好几秒了
- 系统提示词里有一句「已装载本校图书馆全量书目(共 133 万条:纸本多少种、电子书多少种、覆盖多少个分类号)」。这句话原先是让数据库**把 1.31 GB 的馆藏库整个扫一遍**算出来的 —— 每次开程序、每次新建第一个会话都要付这笔钱(有台机器上量到 9.87 秒)。
- 而库里那两个索引**本来就在**,只是那条查询没用上它们。拆成各走一条索引之后,同一台机器实测**约 1.5 秒降到约 0.2 秒**,**报出来的四个数一个都没变**。
- 两件刻意没做:**没有**为了这件事在你机器上多存一个缓存文件(那种文件要跟着打包清理清单走,而这里用不着);**没有**把"电子书种数"改成用总数减出来 —— 那是拿一个假设换 0.05 秒,不值得。

### 🧩 MCP 服务器的「提示模板」现在能用了
- 有些外接的 MCP 服务器除了工具还会提供**写好的提示模板**(比如"按这个流程审这份配置")。学长早就能读到"那台服务器有哪些模板"这份清单,但一直没有一条路让模型真的去用它们 —— 等于白读一次。
- 现在补上了:你可以说「看看那台 MCP 服务器给了哪些提示」,它列给你(名字、要填什么参数、服务器自己的说明);说「用它那个某某」,它把内容取回来。
- ⚠ **那类模板是"那台服务器写的指示",不是学长自己的规矩**:所以每次取都会问你一句,引用时也会注明来源,里面叫你去做的事仍然由你点头。这条与读 MCP 资源、读网页内容是同一道门。
- 网页版和"把学长接给别人当 MCP 服务"那两侧都**没有**这个入口 —— 访客与外部客户端不该能替这台机器决定读什么。

### 📚 顺带修的是仓库自己的账,但对升级的人有用
- **更新日志里那段"消失的九个版本"补回去了**:v0.9.163~171 那九版当时在工作树里写完一直没单独提交,最后由一笔"收编"一起落地 —— 于是生成的变更索引从 v0.9.162 直接跳到 v0.9.172,看起来像那九版没发生过。现在那一段底下会明写"这 9 个版本号没有单独成段,逐版内容读这份文档"。
- 那份八家竞品能力对照表(我们自己的那一列)回填到了现状:上一版停在 v0.9.138,而中间落了三十多个版本。这一轮回改了十格、补了十四格从没标记过的维度。**顺手查掉一处自己写进去的假账** —— 「上下文压缩会吃掉对话级回滚」不成立:留档是追加式的,压缩只补一行标记、旧消息一行不抹,恢复会把压缩前的历史整份放回来。所以那一格改为"已成立",而真正欠的那半写清楚了:压缩这件事不跨重启(重启后会再压一次,多花一次摘要调用)。

### 上一个版本(v0.9.174)的主干,一并进包
- **浅色主题下那批「看不见的文字」修好了** —— 根因是那九个颜色名字在代码里从来没定义过,退回的是照着深色写的白值(详见 v0.9.174 说明)。
